MUST KNOW / 先记住

开始操作前的强制规则

  1. 先处理审批和阻塞队列，再做导出与月结。
  2. 发票、付款凭证、收据是不同对象，不可互相代替。
  3. 作废保留审计记录，不用删除掩盖错误。
  4. Credit Note 只减少已开合作方发票，不直接改原发票金额。
页面、权限或状态与 SOP 不一致时，停止会影响课包、财务、工资、合同、家长可见内容或真实课次的操作，并向主管确认。

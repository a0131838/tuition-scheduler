MUST KNOW / 先记住

开始操作前的强制规则

  1. 先确认课次实际学生和老师，再点名。
  2. 请假免扣、取消和正常扣课不能混用。
  3. 反馈必须基于真实课堂，不复制模板敷衍。
  4. 错误点名或错学生反馈必须走更正并保留审计。
页面、权限或状态与 SOP 不一致时，停止会影响课包、财务、工资、合同、家长可见内容或真实课次的操作，并向主管确认。

管理原则 / Management principles

01
中文
  1. 先看重点卡和红色数字。
  2. 管理监督，不代替教务逐条发送。
  3. 老师原文与家长展示版分开。
  4. 自动提醒与人工微信分开。
  5. 错误通过更正，不删除记录。
  6. 双身份使用两个账号并从账号管理切换。
English
  1. Start with priority and red counters.
  2. Management supervises without replacing operations.
  3. Keep teacher original and parent-facing content separate.
  4. Track automatic and manual delivery separately.
  5. Correct errors without deleting history.
  6. Use separate accounts for dual roles.

监督家长沟通任务 / Monitor communication tasks

04
中文
  1. 打开“家长沟通与通知”。
  2. 先筛“需更正”，再看全部待处理。
  3. 检查是否未领取、负责人是否均衡。
  4. 抽查自动与人工状态、群名/对象和截图证据。
  5. 超时任务立即转交或升级。
English
  1. Open Parent Communication.
  2. Filter Corrections first, then all open tasks.
  3. Check ownership and workload balance.
  4. Sample automatic/manual status, destination, and evidence.
  5. Transfer or escalate overdue tasks.
红框：状态、负责人、自动/人工结果和发送动作。 / Status, owner, delivery channels, and evidence.

提醒异常 / Reminder exceptions

05
中文
  1. 首页点“提醒异常”。
  2. 查看缺少订阅授权或发送失败的对象。
  3. 确认是否已通过微信群人工补发。
  4. 需要家长重新授权时由教务跟进。
  5. 异常为 0 或均有负责人后完成。
English
  1. Open Reminder Exceptions.
  2. Review missing authorization or failed recipients.
  3. Confirm manual WeChat coverage.
  4. Assign staff to request renewed authorization when needed.
  5. Complete when zero or explicitly owned.
红框：待跟进数量和异常列表。 / Follow-up count and exception list.

排课工作台监督 / Schedule workbench oversight

06
中文
  1. 打开课程工作台。
  2. 月历是正式课程；待排工单不是课程。
  3. 关注逾期、冲突、待补信息和异常升级。
  4. 抽查改课动作是否关联原课程。
  5. 不能绕过课包、资格、可用时间和冲突门禁。
English
  1. Open Course Workbench.
  2. The calendar is formal; pending Tickets are not lessons.
  3. Watch overdue, conflict, missing-data, and escalation states.
  4. Check that changes reference the source lesson.
  5. Never bypass package, qualification, availability, or conflict gates.

错误事件处理 / Incident response

08
中文
  1. 先停止旧信息传播。
  2. 确认正确课表/反馈。
  3. 创建并发送更正。
  4. 保留旧记录和新截图。
  5. 网页版审计日志复原时间线。
  6. 分类根因：数据、流程、权限、培训或系统。
English
  1. Stop stale information.
  2. Verify correct schedule/feedback.
  3. Create and send correction.
  4. Preserve original and correction evidence.
  5. Use web audit logs for the timeline.
  6. Classify root cause.
禁止：删任务、改数据库掩盖、换账号重做、只在微信口头处理。 / Never erase, hide, switch identities to redo, or resolve only verbally.

Jasmine 管理/老师双账号 / Jasmine dual identities

09
中文
  1. 首页底部点“账号管理”。
  2. 分别绑定管理账号和老师账号。
  3. 管理身份用于排课、审核、监督和账号管理。
  4. 老师身份用于本人课程、点名、反馈和工资。
  5. 切换后必须核对首页角色。
English
  1. Open Account Management.
  2. Bind Admin and Teacher accounts separately.
  3. Use Admin for scheduling, review, oversight, and access.
  4. Use Teacher for personal lessons, attendance, feedback, and payroll.
  5. Verify the Home role after switching.
培训账号只有一个身份；Jasmine 实际绑定后会列出两个账号。 / The training account has one identity; Jasmine will see two.

权限与离职 / Access and offboarding

11
中文

老师只看本人教学；教务处理沟通和排课协调；管理查看全局并配置权限。离职/调岗当天停用账号、撤销小程序绑定、转交未完成任务，保留历史日志。

English

Teachers see their own teaching; Academic Operations handles communication and coordination; Management oversees and configures access. Disable accounts/bindings and transfer work on the same day of offboarding while preserving history.

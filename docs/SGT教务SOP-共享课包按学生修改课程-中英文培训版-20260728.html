Prepare / 准备

  • Use your own account and the workspace assigned to your role. / 使用本人账号和岗位对应工作台。
  • Use training data unless your manager explicitly authorises real data. / 除非主管明确授权，否则只用培训数据。
  • Prepare the correct student, teacher, date, owner, package, invoice, or task reference. / 准备正确的学生、老师、日期、负责人、课包、发票或任务资料。
  • Keep this PDF open beside the system and complete one numbered step at a time. / 将本 PDF 与系统并排打开，每次只完成一个编号步骤。

Never guess / 禁止猜测

  • Do not guess names, amounts, dates, statuses, permissions, or missing fields. / 不猜测姓名、金额、日期、状态、权限或缺失字段。
  • Do not use another employee's account. / 不使用其他员工账号。
  • Do not repeat Save, Apply, Approve, Issue, Publish, or Send when the result is unclear. / 结果不明确时，不重复点击保存、应用、批准、签发、发布或发送。
  • Stop and ask the workflow owner when the page differs. / 页面不一致时停止并询问流程负责人。

END-TO-END WORKFLOW / 完整操作流程

Change a Course for One Student in a Shared Package
共享课包按学生修改课程

1
Open the target shared package and verify every linked student and current course.进入目标共享课包并核对所有关联学生和当前课程。
2
Choose the per-student change action; do not change the package-wide course.选择“按学生修改”，不得修改共享课包的全局课程。
3
Select only the target student and new course; recheck the name before saving.只选择目标学生和新课程，保存前再次核对姓名。
4
Check the target student's new course, balance, and scheduling eligibility.检查目标学生的新课程、余额和后续排课资格。
5
Sample-check that other students' courses and balances are unchanged and save evidence.抽查其他学生课程和余额未变化，保存验收证据。

MUST KNOW / 先记住

开始操作前的强制规则

  1. 先查重再新增资源。
  2. 每次跟进必须有结果、下一步和日期。
  3. 学校指南咨询只能依据已核实资料，不承诺录取概率。
  4. 成交后必须交接到学生、合同或排课工单，不能停在聊天记录。
页面、权限或状态与 SOP 不一致时，停止会影响课包、财务、工资、合同、家长可见内容或真实课次的操作，并向主管确认。

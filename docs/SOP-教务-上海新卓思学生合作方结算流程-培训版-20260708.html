Academic Operations SOP / 教务培训流程

上海新卓思学生应该怎么处理
Sister Company 合作方学生结算流程

这份 SOP 给教务使用：当学生来源是 上海新卓思 （Sister Company) 时，如何确认学生归属、设置课包结算模式、 检查费率入口，并把符合条件的课包送入合作方结算与账单流程。

适用角色教务 / Admin
正确入口Students + Partner Settlement
版本日期2026-07-08

一句话答案

新卓思学生 = 学生来源为“上海新卓思 （Sister Company)”的学生。 教务要先确认来源，再确认课包模式是 Online: Package End / 线上：课包完结，之后才会进入合作方结算。
注意： 费率现在只在 Partners / 合作方配置 页面修改；合作方结算页只显示当前费率，不再直接保存费率。

先记住

  1. 系统先用 学生来源 判断学生属于哪个合作方。
  2. 上海新卓思的来源必须是：上海新卓思 （Sister Company)。
  3. 只有课包结算模式设置为 Online: Package End 或线下月结模式，才会进入合作方结算。
  4. 费率变更只影响后续生成的结算记录；已经生成的记录保留当时保存的金额。
  5. 看不到学生时，先确认学生列表是否在 All Students / 全部学生 视图，不要只看“今日新增”。

完整流程

  1. 在 Partners / 合作方配置 确认上海新卓思的学生来源、费率和默认课包规则。
  2. 在 Students / 学生 页面筛选来源，确认学生确实属于上海新卓思。
  3. 打开学生课包，确认或设置结算模式为 Online: Package End。
  4. 进入 Partner Settlement / 合作方结算，选择上海新卓思和月份。
  5. 处理线上待结算项，生成待开票记录。
  6. 进入 Open Billing Workspace / 打开账单工作区，交给财务继续开票、收款、收据。

步骤 1：确认合作方配置

Partner Setup

先确认系统里“上海新卓思”绑定了正确学生来源。这个配置决定系统怎么分辨新卓思学生。

操作：
  • 进入 Partners / 合作方配置。
  • 找到 上海新卓思。
  • 确认 Student source 是 上海新卓思 （Sister Company)。
图 1： 费率、课时分钟数、默认课包分钟数都在合作方配置页维护；结算页不再改费率。

步骤 2：筛选上海新卓思学生

Students

教务在学生列表里确认来源。新卓思历史学生不一定是今天新增，所以要看全部学生视图。

操作：
  • 进入 Students / 学生。
  • 视图选择 All Students / 全部学生。
  • 来源筛选为 上海新卓思 （Sister Company)。
图 2： 当前系统筛选后显示 3 名上海新卓思学生。若数量不对，先检查学生来源。

步骤 3：进入合作方结算中心

Partner Settlement

选择上海新卓思和对应月份。页面顶部会显示线上待结算、待开票记录和异常数量。

操作：
  • 进入 Partner Settlement / 合作方结算。
  • Partner 选择 上海新卓思。
  • 选择月份后点击 Apply / 应用。
图 3： 先确认合作方、学生来源、月份，再从待处理队列开始，不要直接去历史记录里找。

步骤 4：检查费率与课包模式

Rate + Package Mode

费率是只读展示；如果要改费率，去合作方配置。教务重点检查每个学生课包的 Mode 是否正确。

操作：
  • 打开 Settlement setup / 结算配置。
  • 确认费率只是显示，不在这里改。
  • 确认课包 Mode 是 Online: Package End / 线上：课包完结。
图 4： 课包模式不对时，学生来源正确也不会进入对应结算流程。

步骤 5：进入账单工作区

Billing Workspace

教务生成待开票结算记录后，账单工作区用于后续发票、付款记录、收据和审批。

操作：
  • 点击 Open Billing Workspace / 打开账单工作区。
  • 确认 Partner、Mode、Month 没选错。
  • 后续按 Create Invoice → Payment records → Create Receipt 顺序处理。
图 5： 进入账单工作区前先确认金额和数量；这里通常由财务继续开票收款。

常见错误

错误 1：来源写错

如果学生来源不是 上海新卓思 （Sister Company)，系统不会把这个学生归到上海新卓思。

错误 2：只看今日新增

历史学生不会出现在 Today New Students。要切到 All Students / 全部学生 再筛选来源。

错误 3：课包模式为空

学生来源正确，但课包 Mode 没设，仍然不会进入合作方结算。

错误 4：想在结算页改费率

现在结算页费率只读。需要改费率时，点击 Edit in Partner Setup / 去合作方配置修改。

不要做： 不要为了让学生进入结算而随便改学生来源。来源代表业务归属，必须和实际合作方一致。

最终检查表

  • 学生来源 = 上海新卓思 （Sister Company)
  • 学生列表使用 All Students / 全部学生 视图时能筛到该学生
  • 课包 Mode = Online: Package End / 线上：课包完结
  • 合作方结算页 Partner = 上海新卓思
  • 月份选择正确，点击 Apply / 应用 后再处理队列
  • 费率如需调整，只去 Partners / 合作方配置
  • 已生成结算记录的金额不会因后续改费率自动变化

遇到问题先问谁

  1. 来源不确定：先问负责该学生的教务/销售确认合作方归属。
  2. 课包模式不确定：先问管理或财务，确认是线上课包完结还是线下月结。
  3. 费率不确定：不要在结算页处理，先到合作方配置核对。
  4. 金额已经生成但感觉不对：不要直接开票，先撤回/核对后再重新生成。

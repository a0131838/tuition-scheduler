Finance Training SOP / 财务培训流程

老师收款资料核验与导出流程 / Tutor Payment Profile Review and Export

本流程只给财务/Admin 使用。新规则是：本地老师 PayNow，海外老师 Wise；Bank Transfer 只作为历史资料参考。工资、报销和 tutor cost 金额计算逻辑不变。
This guide is for Finance/Admin only. New rule: local tutors use PayNow, overseas tutors use Wise. Bank Transfer is legacy reference only. Payroll, reimbursement, and tutor-cost amount calculations are unchanged.

对象 / AudienceFinance / Admin
系统区域 / AreasTeacher Payroll, Expense Claims, Teachers
版本 / Version29 May 2026

一句话 / Short Answer

付款前先看 Payment Method 和 Payment Profile Status。PayNow 用 PayNow 栏位，Wise 用 Wise 栏位；历史 Bank Transfer 只作参考。
Before paying, check Payment Method and Payment Profile Status. Use PayNow columns for PayNow, Wise columns for Wise, and legacy Bank Transfer only as reference.

先记住 / Must-Know Rules

  1. Pending Review：老师刚提交或修改，财务未核验，付款前不要直接使用。 / Tutor has just submitted or updated details; Finance has not verified them yet. Do not use directly for payout.
  2. Verified：财务已核验，可用于付款导出。 / Finance has verified the profile; it can be used for payout exports.
  3. Rejected：资料有问题，必须让老师补资料。 / Details are incomplete or unsafe; ask the tutor to correct them.
  4. Payment Method 是 PayNow 时，只使用 PayNow 栏位。 / When Payment Method is PayNow, use PayNow columns only.
  5. Payment Method 是 Wise 时，只使用 Wise 栏位。 / When Payment Method is Wise, use Wise columns only.
  6. 历史 Bank Transfer 栏位不等于新的付款方式。 / Legacy Bank Transfer columns are not a new payment method.

流程总览 / Workflow

  1. 老师提交 Payment Details。 / Tutor submits Payment Details.
  2. 财务/Admin 在老师资料中核验。 / Finance/Admin reviews the teacher profile.
  3. 资料正确设为 Verified；不正确设为 Rejected 并写原因。 / Mark correct details as Verified; mark incorrect details as Rejected and write the reason.
  4. 工资、报销或 tutor cost 导出时检查付款资料列。 / Check payment-profile columns in payroll, reimbursement, or tutor-cost exports.
  5. 付款后按原有流程更新 paid/claim/payroll 状态。 / After payment, update paid/claim/payroll status through the existing workflow.

Teacher Profile

列 / Column用途 / How Finance should use it

异常情况 / Special Cases

资料空白 / Blank Details

不要付款。让老师回 Payment Details 补资料。 / Do not pay. Ask the tutor to update Payment Details.

状态 Pending Review / Pending Review

先核验。确认无误后设为 Verified。 / Review first. Mark as Verified only after confirming.

名字不一致 / Name Mismatch

先核对身份和备注；不能确认就 Rejected。 / Check identity and notes first; if unsure, mark Rejected.

必须特殊付款 / Special Payment Required

不要改系统金额；单独记录原因和资料来源。 / Do not change system amounts; record the reason and source separately.

常见错误 / Common Mistakes

  • 只看 PayNow 字段有值，没有看 Payment Method。 / Using PayNow fields just because they are filled, without checking Payment Method.
  • 看到历史 Bank Account 就直接银行转账。 / Making a bank transfer just because legacy Bank Account fields exist.
  • 老师重新修改后，仍使用旧的 Verified 结论。 / Reusing an old Verified decision after the tutor has updated details.
  • 把付款导出表发到普通群聊。 / Sending payout export files to normal group chats.

付款前检查 / Final Checklist

  1. Tutor Code 和 Teacher Name 已核对。 / Tutor Code and Teacher Name are checked.
  2. Payment Method 已确认是 PayNow 或 Wise。 / Payment Method is confirmed as PayNow or Wise.
  3. Payment Profile Status 已确认，优先使用 Verified。 / Payment Profile Status is checked; use Verified profiles first.
  4. PayNow 付款前核对显示名称。 / For PayNow, verify the displayed name before payment.
  5. Wise 付款前确认邮箱/电话/WiseTag 至少一种可查找。 / For Wise, confirm at least one searchable identifier: email, phone, or WiseTag.
  6. 历史 Bank Transfer 没有被当作新付款方式。 / Legacy Bank Transfer is not treated as a new payment method.
  7. 付款资料文件按敏感财务资料保存。 / Payout files are stored as sensitive finance data.
提醒 / Reminder: 本功能不改变工资金额、报销审批、课时、排课、发票或收据逻辑。 / This feature does not change payroll amounts, expense approvals, lesson hours, scheduling, invoices, or receipts.

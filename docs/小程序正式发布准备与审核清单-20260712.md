## 2. 微信隐私保护指引资料

主体名称：上海新卓思教育科技有限公司

小程序用途：为已签约/接受服务的学生家长和员工提供学生课表、课后反馈、服务请求、财务资料、课程提醒及移动教务协作。

### 2.1 实际处理的信息

- 微信登录产生的小程序用户标识，用于识别家长或员工绑定关系。
- 家长自行填写的姓名、与学生关系、联系电话。
- 学生姓名、学校、年级、服务类型、学习风险、课表和老师信息。
- 老师发布的课后反馈、作业和学习进展。
- 家长或员工提交的服务请求、文字说明及主动选择的微信聊天文件/截图。
- 课包余额、已付/待付信息、发票、收据及下载记录。
- 微信订阅消息授权结果和消息发送记录。
- 员工姓名、角色、工作区、课程安排及操作审计。

### 2.2 功能用途

- 登录与账号绑定。
- 展示学生课程和学习服务进展。
- 家校沟通、请求跟进和材料上传。
- 财务核对及发票/收据下载。
- 课程、反馈、请求和财务订阅提醒。
- 员工移动办公、权限控制和操作审计。

### 2.3 未使用的能力

- 不使用微信支付。
- 不读取通讯录。
- 不读取相册或自动保存到相册。
- 不获取实时地理位置。
- 不调用摄像头、麦克风或录音。
- 不进行广告画像或向家长营销售卖数据。

### 2.4 仍需 Zhao 提供

- [ ] 隐私保护负责人姓名。
- [ ] 隐私联系邮箱。
- [ ] 隐私联系电话。
- [ ] 营业执照上的公司注册地址。
- [ ] 家长/学生业务数据终止服务后的保留期限。
- [ ] 家长主动上传文件在工单关闭后的保留期限。
- [ ] 财务文件和审计记录的保留期限（需结合公司会计与合规要求确认）。

不要在未确认前自行承诺具体删除天数。微信后台隐私指引必须与真实系统处理方式一致。

## 3. 审核员体验准备

小程序不是公开注册制，审核员需要可完成绑定的测试路径。

- [ ] 提交审核当天，为专用测试学生生成一个新的家长绑定邀请码。
- [ ] 邀请码使用“永久有效直到首次成功使用”，但只提供给微信审核说明。
- [ ] 测试学生不得包含真实学生隐私，应使用“赵测试 2”或新的审核专用测试学生。
- [ ] 测试学生至少准备：1 节未来课程、1 条课后反馈、1 个测试课包、1 张测试发票/收据、1 条测试请求。
- [ ] 审核说明写明：首次进入点击“我有邀请码”，输入审核邀请码，关系/姓名/电话可填写测试值。
- [ ] 审核说明写明：员工端属于内部权限功能，普通家长审核无需绑定员工账号。
- [ ] 若微信要求员工功能体验，再生成独立审核员工账号和一次性员工绑定码，不提供真实员工账号。

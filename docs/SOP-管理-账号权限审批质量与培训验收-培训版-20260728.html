MUST KNOW / 先记住

开始操作前的强制规则

  1. 权限按岗位最小化，不为方便临时扩大长期权限。
  2. 兼职工作台不等于管理员权限。
  3. 重大财务、课包、家长发布和全托管报告必须有复核。
  4. 离职、休假或换岗必须完成权限和未完成事项交接。
页面、权限或状态与 SOP 不一致时，停止会影响课包、财务、工资、合同、家长可见内容或真实课次的操作，并向主管确认。

# 教务小程序代家长录入下月排课完整流程

## 文档信息

- 适用角色：Admin、教务及获准使用 Academic Desk 的员工
- 适用系统：SGT Manage 网页端、博思学业管家员工小程序
- 小程序基准版本：`1.0.23`
- 对应发布：`2026-08-04-r308`
- 更新日期：2026-08-04
- 网页入口：`Admin > Monthly Scheduling / 下月排课确认`
- 小程序入口：`员工端 > 下月排课跟进`

## 一、流程目的

在每月结束前主动确认老生下个月的上课需求。家长可以自行在家长小程序提交，也可以只在微信群、微信私聊或电话中回复，再由教务在员工小程序中代为录入。

每名学生、每门课程必须独立确认。兄弟姐妹即使共用一个课包，也不能把课程需求合并为一条记录。

## 二、必须记住的规则

1. 小程序中的家长确认只形成排课需求，不会直接创建或修改正式课程。
2. 教务代录时必须填写沟通渠道、家长回复日期、家长原话或沟通摘要。
3. 家长要求修改时间时，必须填写可以上课的星期和时段，系统才会生成候选时间。
4. 候选时间最多选择三个，按点击顺序代表第一、第二、第三选择。
5. 系统只临时保留第一个仍可用的候选方案24小时，最终仍须进入正式排课页面保存课程。
6. 已匹配或已正式排课的项目不能通过代录功能覆盖，后续变化必须走再次调整流程。
7. 共享课包只共享余额，不共享学生的年级、课程内容、老师需求或排课需求。

## 三、开始前检查

### 3.1 网页端检查

1. 管理员或教务登录 SGT Manage 网页端。
2. 打开 `Monthly Scheduling / 下月排课确认`。
3. 确认目标月份正确。
4. 确认该月份活动已经创建并处于 `OPEN / 开放` 状态。
5. 同步目标月份的学生课程项目。
6. 检查学生姓名、课程名称、家长绑定和现有课程信息是否正确。

如果网页端没有创建并开放月份活动，员工小程序会显示“当前没有需要处理的学生课程项”。小程序不能代替网页端创建月份活动。

### 3.2 小程序检查

1. 确认手机使用的是博思学业管家开发版或体验版 `1.0.23` 及以上版本。
2. 点击 `进入员工端`。
3. 使用教务员工账号登录。
4. 在员工首页确认可以看到 `下月排课跟进`。

## 四、第一阶段：发送家长确认消息

1. 在员工首页点击 `下月排课跟进`。
2. 进入 `待确认` 或相应待处理队列。
3. 找到正确的学生和课程。
4. 核对学生姓名、课程名称、家长姓名和当前状态。
5. 点击 `复制家长消息`。
6. 将消息粘贴到该学生对应的家长微信群。
7. 确认消息发送成功后，返回小程序。
8. 点击 `标记已发送`。
9. 如需记录沟通情况，在“内部跟进备注”填写内容并点击 `保存备注`。

注意：兄弟姐妹的家庭消息可以合并发送，但系统中的每名学生、每门课程仍须分别录入和完成。

## 五、第二阶段：家长在微信群回复后由教务代录

### 5.1 打开代录页面

1. 在 `下月排课跟进` 中找到对应学生和课程。
2. 点击 `代家长录入/选择`。
3. 核对页面顶部的学生姓名、课程名称、家长姓名和当前状态。
4. 不要在未确认学生和课程的情况下直接录入。

### 5.2 录入家长需求

在“第一步：录入家长需求”中选择家长的实际意思：

- `保持目前安排`：家长希望下个月继续目前安排。
- `希望修改时间`：家长希望更改星期、时间、形式、校区或老师。
- `下个月暂停`：家长明确表示下个月暂停。
- `尚未确定，请联系`：家长暂时不能确定，需要继续跟进。

然后依次填写：

1. 沟通渠道：微信群、微信私聊、电话或其他。
2. 每周次数：家长预计每周上课次数。
3. 预计总分钟：家长明确提出总课时需求时填写，否则可以留空。
4. 上课形式：无偏好、线上或线下。
5. 校区偏好：家长有明确要求时填写。
6. 老师偏好：如实填写，但不能向家长承诺一定安排该老师。
7. 家长需求备注：填写对排课有帮助的补充信息。
8. 家长原话或沟通摘要：必填。
9. 家长回复日期：填写实际收到回复的日期，不能填写未来日期。

建议的沟通摘要格式：

> 家长在李赫轩家长群回复：周二和周四下午可以，周四优先，希望继续线下课程。

### 5.3 家长要求修改时间时的附加信息

当选择 `希望修改时间` 时，还必须填写：

1. 可上课星期：至少选择一个星期。
2. 可用时段：最多填写三组开始和结束时间。
3. 不方便上课日期：仅填写目标月份内的日期，用逗号分隔。

填写完成后点击 `保存并生成候选时间`。

系统会使用以下真实条件生成最多五个候选方案：

- 对应学生和课程；
- 老师是否可以教授该课程；
- 老师目标月份的日期可用时间；
- 老师已有课程和预约；
- 学生已有课程冲突；
- 家长填写的星期、时段和不可上课日期。

### 5.4 不同家长意向保存后的结果

- 保持目前安排：保存需求，不需要家长排序候选时间。
- 希望修改时间：保存需求，并尝试生成具体候选时间。
- 下个月暂停：进入暂停状态，不生成候选时间。
- 尚未确定：保留为待继续跟进，不生成正式课程。

## 六、第三阶段：把候选时间发给家长

1. 候选时间生成后，查看老师、星期、开始时间、结束时间、预计次数和每次时长。
2. 将候选时间整理后发送到对应的家长微信群。
3. 明确要求家长按第一、第二、第三选择回复。
4. 不要把候选时间描述为“已经正式排好”。
5. 告知家长最终以上课前学校确认的正式课表为准。

如果系统没有生成候选时间，说明现有老师可用时间、课程资质或学生时间没有形成完整匹配。此时不要随意选择老师，应回到异常队列继续协调或创建老师例外处理。

## 七、第四阶段：代录家长候选时间排序

1. 收到家长明确回复后，重新进入该学生课程的 `代家长录入/选择`。
2. 滚动到“第二步：代录家长时间排序”。
3. 按家长实际优先顺序点击候选方案。
4. 第一个点击的方案是第一选择，第二个是第二选择，第三个是第三选择。
5. 最多记录三个选择。
6. 选择实际沟通渠道。
7. 填写家长选择原话或摘要。
8. 填写家长实际回复日期。
9. 点击 `按家长排序临时保留24小时`。

建议的选择摘要格式：

> 家长在微信群回复：优先方案2，其次方案1；如果都不行，请再联系家长。

系统会从家长排序中选择第一个仍可用的方案，并进行24小时临时保留。临时保留不是正式课程。

## 八、第五阶段：教务确认并完成正式排课

1. 返回 `下月排课跟进`。
2. 在 `待确认` 队列找到该学生课程。
3. 核对显示的家长首选、老师、星期、时间、次数和临时保留截止时间。
4. 点击 `确认家长首选`。
5. 项目进入已匹配状态后，点击 `打开预填排课`。
6. 在正式排课页面再次检查：
   - 学生；
   - 课程；
   - 老师；
   - 日期；
   - 开始和结束时间；
   - 校区或上课形式；
   - 学生、老师和教室冲突；
   - 课包及财务排课门禁。
7. 确认无误后保存正式课程。
8. 在正式课表中确认课程已经真实存在。
9. 返回 `下月排课跟进`。
10. 点击 `正式课表完成后标记`。

只有正式课表中已经存在目标月份的真实课程，系统才允许完成该项目。不要在正式课程尚未保存时提前标记完成。

## 九、家长自行在家长端操作

如果家长愿意使用小程序：

1. 家长登录博思学业管家。
2. 在首页打开 `下月排课确认`。
3. 逐一选择每名学生和每门课程。
4. 选择保持、修改、暂停或尚未确定。
5. 修改时间时填写可用星期、时段、上课形式和不可上课日期。
6. 提交该学生课程的安排。
7. 学校生成候选时间后，家长按优先顺序选择最多三个方案。
8. 教务仍需确认匹配，并进入正式排课页面完成课程。

家长自行提交与教务代录使用相同的时间匹配和正式排课边界。

## 十、共享课包和兄弟姐妹处理

1. 每名学生、每门课程都有独立的下月确认项目。
2. 不同年级、不同学习内容或不同课程名称必须分别处理。
3. 不能因为共用课包就把哥哥的时间、课程或老师选择复制给妹妹。
4. 家庭微信群中的沟通消息可以一次列出多名孩子，但代录时必须逐项打开对应学生课程。
5. 正式排课后，课包仍按原有共享余额和实际出勤扣课逻辑处理，本流程不改余额。

## 十一、状态和队列说明

- 待确认：家长已经选择候选时间，等待教务确认。
- 等家长：尚未发送、已发送、已查看或等待家长选择候选时间。
- 异常：暂无标准匹配、需要澄清、无回复或需要老师例外协调。
- 已处理：已经匹配、正式排课完成或家长暂停。
- 全部：仅用于查询所有记录。

## 十二、审计记录

教务代录后，系统会记录：

- 代录方式；
- 沟通渠道；
- 操作员工姓名和账号；
- 家长回复日期；
- 家长原话或沟通摘要；
- 候选时间排序及最终临时保留方案；
- 操作前后状态；
- 永久 AuditLog 审计事件。

月度排课 CSV 导出也包含代录和候选排序的审计字段。

## 十三、必须停止并检查的情况

遇到以下情况不要继续操作：

1. 学生或课程显示不正确。
2. 家长没有明确表达需求，教务需要猜测答案。
3. 家长回复属于另一名兄弟姐妹或另一门课程。
4. 候选时间已经过期或被其他学生占用。
5. 页面提示项目状态已经变化。
6. 项目已经匹配或正式排课，却仍需要修改。
7. 正式排课页面出现老师、学生、教室、课包或财务门禁错误。

状态变化提示通常代表另一名员工已经处理过。应刷新页面并重新核对，不能重复提交。

## 十四、常见错误

- 只保存内部备注，没有点击代家长录入。
- 发送家长消息后忘记标记已发送。
- 修改时间时没有选择星期或填写时段。
- 把教务建议写成家长原话。
- 没收到家长确认就替家长排序。
- 把候选时间当成正式课程。
- 正式排课尚未保存就点击完成标记。
- 共享课包的兄弟姐妹只处理其中一人。
- 家长再次调整时直接覆盖已经匹配或排课的记录。

## 十五、完成检查清单

- [ ] 目标月份活动已开放。
- [ ] 学生和课程核对正确。
- [ ] 家长消息已发送并标记。
- [ ] 家长意向逐名学生、逐门课程录入。
- [ ] 沟通渠道、回复日期和原话摘要填写完整。
- [ ] 修改时间时已填写星期、时段和不可上课日期。
- [ ] 候选方案已发送家长。
- [ ] 家长排序按照实际回复录入。
- [ ] 家长首选已由教务确认。
- [ ] 正式排课页面全部冲突和门禁检查通过。
- [ ] 正式课程已真实保存到目标月份课表。
- [ ] 下月排课项目已标记完成。
- [ ] 共享课包中的其他学生课程也已分别处理。

## 十六、功能边界

本流程不会自动执行以下操作：

- 创建、取消、改期或替换正式课程；
- 修改课包总额或剩余余额；
- 扣除课时；
- 修改考勤；
- 开发票、开收据或改变付款状态；
- 生成或修改合同；
- 修改老师工资；
- 自动发送微信群消息；
- 自动关闭排课工单。

所有正式课程仍由教务在原有正式排课页面完成，并继续使用现有的权限、资质、可用时间、冲突、课包和财务门禁检查。

# 教务 SOP：下月家庭排课与例外工作台

版本：2026-08-04 r311

## 一、角色分工

| 角色 | 负责事项 | 不负责事项 |
| --- | --- | --- |
| 系统 | 生成下月活动、归纳上月固定安排、合并家庭提醒、准备候选时间、识别异常 | 不自动发微信，不自动创建正式课程 |
| 教务 Emily/Eva | 核对家庭信息、代录微信回复、处理异常、确认候选方案、进入正式课表排课 | 不手工计算老师容量，不在自由文本中猜老师姓名 |
| 家长 | 在家长小程序确认沿用、修改、暂停或需要联系 | 不直接修改正式课表 |
| 老师 | 按日期提交下月可授课时间，必要时确认例外 | 不直接接受未经教务确认的家长时间 |
| 管理 | 查看完成率、异常量、缺少可用时间的老师和容量缺口 | 不替代教务执行日常逐条排课 |
| 财务 | 只读查看需求和容量，用于人力规划 | 不修改活动、家长回复或正式课表 |

## 二、系统自动准备

1. 每天 08:15 系统检查下一个月的活动。
2. 如果活动不存在，系统建立草稿并同步符合条件的在读学生和课程。
3. 系统读取上一个月的真实课程，归纳星期、时间、老师、校区和时长，显示为“上月安排建议”。
4. 系统不会复制或创建任何正式课程，这个建议只用于减少重复询问。
5. 到开放日期时，活动自动变为开放。
6. 到截止日期后，仍未回复的项目进入“异常”，原因显示“家长逾期未回复”。

## 三、老师先提交可授课时间

1. 老师进入员工小程序的可授课时间页面。
2. 选择下个月的具体日期和时间，不只填写每周模板。
3. 提交后检查目标月份是否已显示真实日期时段。
4. 教务在网页工作台查看“尚未提交可用时间的老师”。
5. 若老师未提交，教务使用固定话术提醒，不在家长群中承诺该老师的时间。

## 四、教务开始当月流程

1. 网页进入 `下月排课确认 / Monthly Scheduling`。
2. 选择目标月份。
3. 先选择学生分组：“博思及其他”或“新东方学生”。来源渠道精确为“新东方学生”的项目只进入新东方队列，其余学生统一进入博思及其他队列。
4. 再看当前分组的四个队列：待确认、等家长、异常、已处理；数量、家庭消息、师资预测和导出均只计算当前分组。
5. 检查缺少可用时间的老师；优先解决这些容量资料，不先逐个联系家长改时间。
6. 打开沟通中心，找到“下月排课”任务。
7. 每个家庭只复制一条系统生成的话术；话术会列出当前分组中已关联的孩子和课程。
8. 发送到正确的家长微信群、私聊或新东方项目对接群后，上传/记录发送凭证并标记已发送。

## 五、家长愿意使用小程序

### A. 全部保持目前安排

1. 家长进入家长小程序的“下月排课确认”。
2. 页面同时显示每个孩子、每门课程和上月安排建议。
3. 如果全部课程都有可沿用安排，点击“全家保持目前安排”。
4. 系统一次确认该家庭所有可编辑项目，并为它们记录同一个家庭批次号。
5. 教务的项目进入“待确认”，等待正式排课。

### B. 希望修改时间

1. 家长在对应孩子和课程下选择“希望修改时间”。
2. 最多填写三个时间窗口。
3. 每个窗口选择优先级：必须满足、优先选择、可以接受。
4. 可选择当前老师、其他合格老师或需要教务核对，不输入自由文本老师姓名。
5. 提交后等待系统准备具体方案。
6. 系统提供方案后，家长最多选择第一、第二、第三顺位。

### C. 暂停或不确定

1. 选择“下个月暂停”会进入已处理的暂停状态。
2. 选择“尚未确定，请联系我”会进入异常队列。
3. 家长不得通过此页面直接取消已经存在的正式课程；正式变更仍由教务执行。

## 六、家长只在微信群回复时由教务代录

1. 教务进入员工小程序“下月排课”，打开对应家庭和课程。
2. 点击“代家长录入”。
3. 选择回复渠道：微信群、微信私聊、电话或其他。
4. 填写家长回复日期和时间。
5. 粘贴家长原话；如内容过长，填写忠实摘要，不能自行补充家长未表达的条件。
6. 家长回复“全部照旧”时，核对页面列出的孩子和课程，再点击“全家保持目前安排”。
7. 家长要求修改时，最多录入三个时间窗口，并分别选择必须满足、优先选择、可以接受。
8. 老师必须从系统提供的合格老师中选择；姓名不确定时选择“需要核对”。
9. 保存后检查操作者、渠道、家长确认时间和原话是否显示完整。
10. 已匹配、已排课或家长已选定临时方案的项目不能被代录覆盖。

## 七、教务每天只处理四个队列

### 1. 待确认

- 包含家长确认沿用、家庭一键沿用和家长已选具体方案。
- 先核对老师真实日期可用时间，再进入原有正式排课页面。
- 正式课表保存成功后，才把项目标为已排课。

### 2. 等家长

- 包含待发送、已发送、已查看和等待家长选择方案。
- 使用系统固定话术跟进，不重新手写长消息。
- 同一家庭只发送一次家庭消息，避免兄弟姐妹重复提醒。

### 3. 异常

- 页面直接显示原因：未回复、需要澄清、没有标准时间匹配、老师需要核对、老师例外确认或正式方案后再次调整。
- 只联系异常家庭，不重新检查所有正常项目。
- 没有合适时间时，先看家长“可以接受”的第三档，再决定是否找老师例外。

### 4. 已处理

- 包含已匹配、已排课、暂停和排除。
- 只用于复核和交接，不重复发送提醒。

## 八、正式排课步骤

1. 在待确认项目点击进入正式排课页面。
2. 核对学生、课程、老师、日期、时间、时长、授课方式和校区。
3. 系统继续执行原有老师资质、老师/学生/教室冲突、预约、课包和重复课程检查。
4. 保存正式课程。
5. 返回下月排课工作台。
6. 点击完成/已排课；系统会验证目标月份确实存在该学生该课程的正式课。
7. 如果验证失败，不要强行完成，先检查正式课程是否保存到正确学生、课程和月份。

## 九、兄弟姐妹与共享课包规则

1. 家庭提醒可以合并，但每个孩子和课程仍是独立项目。
2. 共享课包不会把不同年级、不同课程需求合并。
3. 系统禁止同一家庭的兄弟姐妹同时占用重叠的临时方案。
4. 一个孩子需要改时间时，只修改该孩子对应课程，不影响另一个孩子。
5. “全家保持目前安排”只在每个可编辑项目都有上月或当前安排时出现；缺少安排的项目必须单独确认。

## 十、每日结束检查

1. 待确认中没有已经完成正式排课但未标记的项目。
2. 异常项目都有负责人和下一步。
3. 家长微信回复均已保存渠道、时间和原话/摘要。
4. 没有老师姓名自由输入或身份不明记录。
5. 缺少下月真实可用时间的老师已经提醒。
6. 已发送消息有凭证，未发送任务没有误标完成。
7. 正式课表、家长提醒和下月工作台显示的学生、课程、老师一致。

## 十一、禁止操作

- 不根据上月建议直接创建课程而跳过正式排课检查。
- 不在没有家长原话或确认摘要时进行代录。
- 不把兄弟姐妹的课程合成一个学生项目。
- 不通过自由文本猜老师姓名。
- 不在同一家庭反复发送多条内容不同的提醒。
- 不把临时方案当作正式课表。
- 不为清空队列而错误标记已排课。

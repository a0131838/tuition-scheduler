MUST KNOW / 先记住

开始操作前的强制规则

  1. 排课建议不等于最终落课，必须经过统一预览和冲突检查。
  2. 直接收费课包未通过财务门禁时不得正式排课。
  3. WAITING_EXTERNAL 必须写下一次跟进日期。
  4. 工单完成必须填写完成结果，不可只改状态。
页面、权限或状态与 SOP 不一致时，停止会影响课包、财务、工资、合同、家长可见内容或真实课次的操作，并向主管确认。

WECHAT MINI PROGRAM SOP / 微信小程序培训

教务小程序完整操作 SOP
沟通、工单录入、排课与提醒

手机端用于把微信群消息快速变成工单，审核老师反馈，人工转发家长/老师提醒，上传发送截图，并与正式排课工作台衔接。

先记住 / Essential rules

01
中文
  1. 每天先看红色重点卡。
  2. 家长消息先录工单，不只留在微信。
  3. 老师反馈先审核再发布。
  4. 自动提醒和人工微信分别完成。
  5. 真正发送后才点“确认已人工发送”。
  6. 截图从相册选；微信文件走独立入口。
  7. 需更正优先于普通任务。
English
  1. Start from the red priority card.
  2. Convert family messages into Tickets.
  3. Review feedback before publishing.
  4. Track automatic and manual delivery separately.
  5. Confirm manual send only after actual delivery.
  6. Choose screenshots from Album; WeChat files use a separate action.
  7. Corrections outrank normal tasks.

Home shows today’s lessons, family requests, and overdue scheduling. The orange Create Ticket card is Emily’s daily intake entry; the list below opens communication, schedule, coordination, requests, and reminder exceptions.

傻瓜式录入工单：第一步 / Guided intake: Step 1

04
中文
  1. 点橙色“立即录入工单”。
  2. 搜索并选择学生。
  3. 回答“家长想要做什么”，选择新增课、改时间、换老师、取消/请假等动作。
  4. 改课类必须选择原课程。
English
  1. Tap Create Ticket.
  2. Search and select the student.
  3. Select the requested action: new lesson, reschedule, replace teacher, cancel/leave, etc.
  4. Change actions must reference the original lesson.
红框：学生、动作、原课程三步引导。 / Student, action, and source lesson.

录入工单：原话、摘要和附件 / Message, summary, attachments

05
中文
  1. 把家长原话粘贴到内部记录。
  2. 另写家长可见摘要，不复制内部敏感内容。
  3. 填写下一步、负责人和截止时间；通常保持默认即可。
  4. 截图点“从相册选择截图”。
  5. PDF/文档点“从微信聊天选择文件”。
  6. 提交前确认学生、动作、原课程和附件。
English
  1. Paste the family’s original message into the internal note.
  2. Write a separate parent-visible summary.
  3. Set next step, owner, and due date only when needed.
  4. Use Album for screenshots.
  5. Use WeChat Chat Files for PDFs/documents.
  6. Verify student, actions, source lesson, and attachments before submission.
红框：相册截图与微信聊天文件两个独立入口。 / Separate Album and WeChat File actions.

排课与调课工单 / Scheduling coordination

06
中文
  1. 打开“排课与调课”。
  2. 先筛“已逾期”，再按负责人、学生、课程搜索。
  3. 打开工单核对结构化动作和缺失项。
  4. 等待家长/老师时更新状态和下次跟进。
  5. 只有“双方已确认/可执行”才进入正式排课。
English
  1. Open Scheduling & Changes.
  2. Filter overdue first, then search by owner, student, or course.
  3. Open the Ticket and review structured actions/missing fields.
  4. Update state and follow-up while waiting.
  5. Enter formal scheduling only when both sides are confirmed.
红框：开放/逾期数字、搜索、筛选和工单。 / Open/overdue counts, search, filters, and Tickets.

课程工作台与待排工单 / Calendar and work-order queue

07
中文
  1. 打开“课程工作台”。
  2. 月/周/日切换查看正式课程。
  3. 下方“待排课工单”只显示待办，不是正式课程。
  4. 点工单进入现有安全排课面板。
  5. 必须通过课包、老师资格、可用时间、冲突和二次确认。
English
  1. Open Course Workbench.
  2. Use month/week/day views for formal lessons.
  3. Pending scheduling Tickets are tasks, not lessons.
  4. Open a Ticket into the existing protected scheduling flow.
  5. Package, qualification, availability, conflicts, and confirmation gates still apply.
红框：正式月历和待排工单区。 / Formal calendar and pending work-order queue.

进入家长沟通中心 / Open communication center

08
中文
  1. 首页点“家长沟通与通知”。
  2. 顶部看待处理数量。
  3. 筛选：待处理、待审核、待发送、需更正、已完成。
  4. 先领取任务，避免两个人同时处理。
English
  1. Tap Parent Communication & Notifications.
  2. Read the open count.
  3. Filter open, review, send, correction, or completed.
  4. Claim the task before working to avoid duplicate handling.
红框：状态筛选、领取、自动/人工状态和文案。 / Filters, claim, delivery states, and message.

审核老师反馈 / Review and publish feedback

09
中文
  1. 筛选“待审核”。
  2. 阅读老师原文（只读）。
  3. 编辑家长展示版，保持事实一致。
  4. 内容不足时“退回老师”并写具体原因。
  5. 无误点“审核并发布”。
English
  1. Filter Pending Review.
  2. Read the teacher original (read-only).
  3. Edit the parent-facing version without changing facts.
  4. Return with a specific reason when incomplete.
  5. Tap Review & Publish when correct.
发布前：检查学生、课程、时间、老师；不得出现其他学生、内部评价、费用争议或未经确认诊断。 / Verify recipient and facts; remove unrelated/sensitive content.

人工转发微信群 / Manual WeChat forwarding

10
中文
  1. 核对自动生成文案。
  2. 填写家长群名或老师微信。
  3. 点“复制文案”或“保存转发图片”。
  4. 到微信实际发送。
  5. 回小程序点“上传发送截图”。
  6. 最后点“确认已人工发送”。
English
  1. Review the generated message.
  2. Enter the family group or teacher contact.
  3. Copy text or save the share image.
  4. Send it in WeChat.
  5. Return and upload the send screenshot.
  6. Finally tap Confirm Manual Send.
红框：复制、保存图片、上传截图、重试和确认发送。 / Copy, image, evidence, retry, and confirm.

明日家长与老师提醒 / Tomorrow reminders

11
中文

系统按一个学生/家庭一条、一个老师一条汇总明日课程。家长提醒含时间、课程、老师和地点；老师提醒含本人全部明日课程。自动提醒和人工微信必须分别看状态。

English

The system consolidates one reminder per family/student and one per teacher. Family messages include time, course, teacher, and location; teacher messages include all assigned lessons. Automatic and manual delivery remain separate.

时间建议：每天 17:00 前人工发送；临时变更立即走更正。 / Send manually by 17:00; handle late changes immediately.

改课后的更正 / Corrections after changes

12
中文
  1. 改时间、换老师或取消后，旧自动提醒会失效。
  2. 若旧人工消息已发，系统生成高优先级“需更正”。
  3. 核对最新课表，发送“请以本条为准”的更正文案。
  4. 发到原群/原对象，上传截图并确认。
English
  1. Old automatic reminders become invalid after schedule changes.
  2. If an old manual message was sent, a high-priority correction appears.
  3. Verify the latest schedule and send the correction.
  4. Send to the original recipient, upload evidence, and confirm.
优先级：需更正永远先于普通待审核和普通提醒。 / Corrections always come first.

自动提醒失败与提醒异常 / Auto failure and reminder exceptions

13
中文
  1. 查看任务中的自动提醒状态。
  2. 失败时确认对象和订阅授权。
  3. 点击“重试自动提醒”。
  4. 首页“提醒异常”集中查看缺授权消息。
  5. 人工已发送不代表自动成功。
English
  1. Read the automatic delivery status.
  2. For failure, verify recipient and subscription authorization.
  3. Tap Retry Automatic Reminder.
  4. Use Reminder Exceptions for missing authorization.
  5. Manual success does not imply automatic success.

领取、转交、无需发送与日志 / Ownership, waive, and audit

14
中文

准备处理先领取；换班时转交给 Emily/Eva 并写备注。只有明确无需人工发送时才“无需发送”并说明原因。领取、发布、复制、上传、发送、重试和豁免都会写日志。

English

Claim before working; transfer to Emily/Eva with a note during handover. Waive only when manual delivery is genuinely unnecessary and record a reason. All key actions are audited.

不能豁免：找不到群、忘记发送、内容不确定。 / Do not waive because the group is missing, the send was forgotten, or content is uncertain.

常见错误 / Common mistakes

15
错误正确处理 / Correct action
只在微信回复，不录系统立即补录工单并保留原话。 / Create a Ticket.
未发送先确认先实际发送、截图，再确认。 / Send, screenshot, then confirm.
改课不选原课程返回选择准确原 Session。 / Select the exact source lesson.
把内部原话发给家长使用独立家长摘要/展示版。 / Use parent-facing content.
重复点击等待并检查状态/日志。 / Wait and verify state/audit.

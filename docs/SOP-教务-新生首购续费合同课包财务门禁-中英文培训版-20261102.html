中文版 · 完整步骤总览

首购续费、合同课包与财务门禁

1先查学生、现有合同和课包，判断首购或续费，禁止重复建档。
2核对家长资料、签约主体、课程、金额、有效期和购买类型。
3发送当前正式合同链接；签署后检查状态、PDF 和事件记录。
4在 Package Billing 创建或关联正确发票；已有发票不得重复开票。
5直接收费课包通过规定审批后才可排课，付款与收据由财务闭环。

先记住：7 条操作原则 / Seven operating principles

01
中文
  1. 每天先同步，再分工。
  2. 老师原文只读，不直接改。
  3. 家长展示版审核后才发布。
  4. 小程序自动提醒与微信群人工发送是两条独立记录。
  5. 人工发送必须有群名/对象，建议上传截图。
  6. 改课或取消后，旧提醒不能继续使用。
  7. 任何错误都通过更正任务处理，不删除历史。
English
  1. Sync first, then assign work.
  2. Teacher original is read-only.
  3. Publish only after reviewing the parent-facing version.
  4. Automatic miniapp and manual WeChat are separate records.
  5. Manual sending needs a destination; upload evidence whenever possible.
  6. Never reuse an old reminder after reschedule/cancellation.
  7. Correct mistakes through a correction task; never erase history.

每天上班、午间、下班前至少各同步一次。先处理“需更正”，再处理“待审核”，最后清理“待发微信群”。

页面入口 / Entry：管理后台侧栏 Today / 今天 → Parent Communication / 家长沟通与通知。

进入沟通中心并读懂数字 / Open the desk and read the counters

03
中文
  1. 点击侧栏“家长沟通与通知”。
  2. 看顶部五个数字：待处理、待审核、待发微信群、需更正、已人工发送。
  3. 点击“同步反馈与明日提醒”。
  4. 等待成功提示后再分工。
English
  1. Open Parent Communication from the Today section.
  2. Read the five counters: Open, Pending Review, Ready for WeChat, Attention, Completed.
  3. Click Sync Feedback and Tomorrow Reminders.
  4. Wait for success before assigning tasks.
红框：同步按钮、状态数字、筛选和人工发送区。 / Red boxes: sync, counters, filters, and manual-send controls.

领取、转交与交接 / Claim, transfer, and handover

04
中文
  1. 准备处理时先点“领取任务”。
  2. 如由另一位教务负责，从“转交给…”选择 Emily 或 Eva。
  3. 不要两个人同时编辑同一条。
  4. 下班前把未完成任务转交给在岗人员，并在备注写原因。
English
  1. Click Claim before working on a task.
  2. Use Transfer to assign Emily or Eva.
  3. Do not edit the same task simultaneously.
  4. Before handover, transfer unfinished tasks and record the reason in Notes.
分工建议 / Recommended split：Emily 负责当日家长群和紧急更正；Eva 负责反馈审核与老师提醒。可按当天值班互换，但系统负责人必须明确。 / Suggested default: Emily handles family groups and corrections; Eva handles feedback review and teacher reminders.

审核老师原文 / Review the teacher original

05
中文
  1. 筛选“待审核反馈”。
  2. 左侧阅读老师原文：课程事实、学生表现、作业、下一步。
  3. 核对是否与课程/学生匹配。
  4. 老师原文只读；不要复制到外部文档后覆盖。
English
  1. Filter Pending Review.
  2. Read the teacher original for facts, performance, homework, and next steps.
  3. Verify it matches the lesson and student.
  4. The original is read-only; never overwrite it externally.
可发布 / Publishable需退回 / Return
事实具体、语气客观、有下一步。 / Specific facts, objective tone, clear next step.学生/课程错误、内容过短、复制旧反馈、内部敏感措辞、缺作业或下一步。 / Wrong student/lesson, too vague, copied content, sensitive wording, missing next step.

编辑家长展示版并发布 / Edit parent-facing version and publish

06
中文
  1. 右侧编辑“家长展示版”。
  2. 保留事实，不改变老师的专业判断。
  3. 把内部措辞改为家长能理解、可行动的表达。
  4. 确认学生、课程、时间和老师无误。
  5. 点击“审核并发布到家长端”。
  6. 发布后家长小程序可见，并进入提醒/转发流程。
English
  1. Edit the Parent-facing version on the right.
  2. Preserve facts and professional judgment.
  3. Convert internal wording into clear, actionable family language.
  4. Verify student, course, time, and teacher.
  5. Click Review and Publish to Parent.
  6. After publishing, the parent miniapp can display it and notification workflows begin.
发布前检查 / Pre-publish check：不能出现其他学生姓名、老师内部评价、费用争议或未经确认的诊断。 / Never include another student’s name, internal staff comments, fee disputes, or unverified diagnoses.

退回老师补充 / Return feedback for revision

07
中文
  1. 点击“退回老师补充”。
  2. 原因必须具体：缺什么、哪里错、要补到什么程度。
  3. 老师端变为“已退回”。
  4. 老师重新提交后，任务回到“待审核”。
English
  1. Click Return to Teacher.
  2. Write a specific reason: what is missing, what is wrong, and what good looks like.
  3. The teacher sees Returned.
  4. After resubmission, the task returns to Pending Review.
正确退回原因 / Good reason：“请补充本节具体学习内容、学生完成情况及下节建议；当前只有‘表现不错’，无法给家长形成行动建议。” / “Please add lesson content, observed performance, and next-step advice; ‘did well’ alone is not actionable.”

微信群人工转发 / Manual WeChat forwarding

08
中文
  1. 筛选“待发微信群”。
  2. 核对自动生成的中英文文案。
  3. 填写家长群名或老师微信对象。
  4. 点击“复制微信群文案”或“下载转发图片”。
  5. 在微信中粘贴/发送。
  6. 回系统上传相册里的发送截图。
  7. 最后点击“确认已人工发送”。
English
  1. Filter Ready for WeChat.
  2. Review the generated bilingual message.
  3. Enter the family group or teacher contact.
  4. Copy text or download the share image.
  5. Send it in WeChat.
  6. Return and upload the screenshot from the photo album.
  7. Click Confirm Manual Send.
红框：复制文案、下载图片、上传发送截图、确认已人工发送。 / Red box: copy, download, upload evidence, and confirm.

上传截图：必须从相册选 / Upload evidence from the photo album

09
中文
  1. 在微信发送后截屏。
  2. 回到系统点“上传发送截图”。
  3. 小程序会打开相册/媒体选择，不要求从微信聊天记录选文件。
  4. 选择刚才截图并确认。
  5. 看到“已上传发送截图”后，再点确认发送。
English
  1. Take a screenshot after sending in WeChat.
  2. Return and tap Upload Send Screenshot.
  3. The miniapp opens the photo/media picker; you do not need to choose a file from WeChat chat history.
  4. Select the new screenshot.
  5. Wait for Evidence Attached, then confirm the send.
不要提前确认 / Do not confirm early：“确认已人工发送”是业务完成动作，不是保存草稿。未真正发送前不能点击。 / Confirm Manual Send marks the business task complete; never click it before actual delivery.

明日家长与老师课程提醒 / Tomorrow reminders

10
中文
  1. 点击同步，系统按“一个学生/家庭一条、一个老师一条”汇总明日课程。
  2. 家长提醒含时间、课程、老师、地点。
  3. 老师提醒含本人全部明日课程和学生。
  4. 分别通过微信群/老师微信人工发送。
  5. 自动提醒状态单独显示：未入队、待发送、已发送、失败、失效。
English
  1. Sync to generate one consolidated reminder per family/student and one per teacher.
  2. Family reminders include time, course, teacher, and location.
  3. Teacher reminders include all assigned lessons and students.
  4. Send through family groups or direct teacher WeChat.
  5. Automatic status is tracked separately: not queued, pending, sent, failed, or skipped.
执行时间 / Timing：建议每天 17:00 前完成次日家长和老师人工提醒；临时改课按更正流程立即处理。 / Complete tomorrow’s manual reminders by 17:00; handle late changes immediately through correction.

改时间、换老师、取消后的更正 / Corrections after schedule changes

11
中文
  1. 系统发现课程内容变化，会使旧自动提醒失效。
  2. 若旧人工提醒已发送，会创建高优先级“更正通知”。
  3. 先核对最新课表，再复制带“请以本条为准”的更正文案。
  4. 立即发到原群/原对象。
  5. 上传截图并确认已发送。
English
  1. The system invalidates stale automatic reminders when the lesson changes.
  2. If an old manual reminder was already sent, a high-priority Correction task is created.
  3. Verify the latest schedule, then send the correction marked “please use this latest message.”
  4. Send to the original group/contact immediately.
  5. Upload evidence and confirm completion.
优先级 / Priority：“需更正”永远高于普通待审核和次日提醒。 / Attention corrections always outrank normal reviews and reminders.

自动提醒失败与重试 / Automatic notification failure and retry

12
中文
  1. 先确认人工微信群是否已经完成；两者不要混淆。
  2. 查看自动状态：失败、待授权或未入队。
  3. 确认家长/老师已授权且对象正确后，点击“重试自动提醒”。
  4. 重试后再次同步查看状态。
  5. 仍失败时记录任务、对象、时间和错误，交管理员处理。
English
  1. First verify whether manual WeChat is complete; keep the two channels separate.
  2. Read the automatic status: Failed, pending authorization, or not queued.
  3. After confirming authorization and recipient, click Retry Automatic Reminder.
  4. Sync again and recheck status.
  5. If it still fails, escalate with task, recipient, time, and error.

无需发送与特殊情况 / Waive and special cases

13
中文

只有明确不需要人工通知时才点“无需发送”，并写原因，例如：家庭明确要求仅小程序接收、测试数据、重复任务经确认、课程已取消且从未通知。

不能用“无需发送”隐藏忘记转发、找不到群或不确定内容。

English

Use Waive only when manual delivery is genuinely unnecessary, and always record a reason: family opted for miniapp only, confirmed test/duplicate task, or a cancelled lesson that was never communicated.

Never use Waive to hide a missed send, missing group, or uncertain content.

情况 / Case处理 / Action
找不到群转交/联系负责人补群名，不豁免。 / Find the owner and group; do not waive.
重复任务核对 task 内容和时间，确认后写明重复来源。 / Verify exact duplicate and record source.
家长不看小程序仍完成人工微信群发送。 / Complete manual WeChat.

日志、查错与交接 / Audit trail, error recovery, handover

14
中文
  1. 展开“查看操作记录”可见领取、转交、发布、复制、上传、发送、重试、豁免。
  2. 点错后不要删除；立即记录并做更正。
  3. 交接时说明：未完成数量、需更正、自动失败、无群名、等待老师补充。
English
  1. Open View Audit Trail to see claim, transfer, publish, copy, upload, send, retry, and waive actions.
  2. Do not delete mistakes; record and correct them.
  3. Handover must include open count, corrections, auto failures, missing group names, and returned feedback.
完成标准 / Definition of done：“需更正=0”；当天到期任务有明确负责人；已人工发送有群名/对象与截图；失败项已重试或上报。 / Attention is zero; every due task has an owner; manual sends have destination/evidence; failures are retried or escalated.

# 教务老师选择与家长固定话术 SOP

版本：2026-08-04 V1

适用角色：教务/CS、管理、家长

原则：排课偏好不等于正式排课；模板生成不等于消息已发送。

## 一、教务代家长录入老师偏好

1. 员工小程序进入“下月排课跟进”，打开对应学生和课程，再点“代家长录入”。
2. 核对学生、课程和家长，确保共享课包中的兄弟姐妹没有选错。
3. 在“老师偏好”选择一种状态：
   - 不指定老师：家长只确认时间或模式。
   - 沿用当前老师：仅当当前课表存在一位明确且具备该课程资格的老师时使用。
   - 选择合格老师：从系统按该课程筛选的老师名单中选择，不能手输姓名。
   - 家长提到老师，待核对：老师不在名单或家长只说了昵称时使用，并记录家长原话。
4. 填写家长可上课星期、时间、校区、模式和其他要求。
5. 填写沟通渠道、家长回复日期、家长原话或摘要。
6. 点“保存并生成候选时间”。系统保存老师 ID，并优先尝试该老师；没有可用时间时仍保留其他合格老师方案。
7. 将候选时间发给家长，收到回复后按第一、第二、第三选择排序并临时保留。
8. 教务最后仍须进入正式排课页面完成原有资格、冲突、课包和重复课程检查。

## 二、家长自行填写老师偏好

1. 家长进入“博思学业管家”小程序的“下月排课确认”。
2. 分别选择每名学生和每门课程，不能把共享课包理解为同一课程需求。
3. 老师偏好选择“不指定”“沿用当前”“选择老师”或“其他老师请教务核对”。
4. 选择老师时只能从该课程合格名单中选择；其他老师必须填写姓名，由教务核对。
5. 提交后，老师偏好只用于协调，最终以上课前确认的正式课表为准。

## 三、教务使用固定家长话术

1. 员工小程序首页进入“家长话术模板”。
2. 先选业务类别，再选具体场景。
3. 核对模板编号和版本，例如 `MONTHLY_INITIAL · V1 · 已发布`。
4. 按字段填写家长称呼、学生、日期、课程、金额或链接等变量。
5. 点“生成并复制已审批话术”。缺少任何必填变量时系统不会生成。
6. 将复制内容发到正确的家长群或私聊，不要自行改动事实字段、承诺、金额和截止日期。
7. 对沟通工作台中的任务，仍须上传发送凭证并点“确认已人工发送”；仅复制不代表已经发送。
8. 家长另有特殊情况时，把原话记入工单或下月排课审计字段，不要直接修改固定模板正文。

## 四、管理维护模板

1. 网页进入“沟通与提醒工作台”，点“家长话术模板”。
2. 查看 18 个已发布场景、模板编号、当前版本和历史版本。
3. 需要修改时，在对应模板中调整标题、编辑策略或内容，点“另存为新草稿版本”。
4. 先核对变量名称和中英文内容，再发布草稿。
5. 发布后，上一版自动退役；新生成内容使用新版本，旧任务仍保留旧文本和旧版本号。
6. 教务和普通员工只能查看或使用已发布版本，不能发布模板。

## 五、异常处理

- 所选老师不在合格名单：刷新页面；仍不在时改为“待核对”，不要选择相似姓名。
- “沿用当前老师”无法保存：当前课表没有唯一老师，改为选择具体合格老师。
- 模板提示缺少变量：补齐提示的字段，不要用空格或“-”代替真实信息。
- 家长在微信群频繁改时间：每次以最后一条明确回复为准，更新审计摘要；正式排课前只保留候选，不直接改 Session。
- 共享课包学生年级或课程不同：逐个学生、逐门课程录入，老师名单按当前课程分别筛选。

## 六、禁止事项

- 不手输名单内老师姓名。
- 不把老师偏好当成老师承诺或正式课表。
- 不把“复制模板”当成“已发送”。
- 不在模板中加入未经管理确认的退款、折扣、学位、录取或排课保证。
- 不用一个学生的选择覆盖共享课包中另一名学生的需求。

Manager Feedback SOP

适用对象：管理者、教务管理、老师。用途：管理在质量检查后，把课堂观察、表扬、改进建议或需要跟进的事项发送给指定老师；老师在老师端查看并确认已读。

先记住 / Must-Know Rules

这是内部教学质量反馈

  1. 只用于管理给老师做课堂质量沟通。
  2. 不是发给家长的课后反馈。
  3. 不是老师工资、排课或扣课依据。
  4. 老师只能看到发给自己的反馈。

第一版支持什么

  1. 管理给单个老师发送反馈。
  2. 可选关联当天某节课。
  3. 可选择反馈类型。
  4. 老师可以点击 Acknowledge / 确认知悉。

不要这样用 / Do Not Use For

不要在这里填写家长投诉原文、学生敏感隐私、财务付款问题、老师工资争议、排课改动指令。需要排课或财务处理时，请回到对应系统流程。

1. 管理质量检查
2. 选择老师
3. 可选关联课程
4. 写反馈并发送
5. 老师查看
6. 老师确认已读

管理端 Step 1: 打开质量工作台并找到反馈表单

操作 / Actions

  1. 管理登录系统。
  2. 进入 Manager Quality Desk / 管理者质量工作台。
  3. 找到 Manager Feedback to Teacher / 给老师的管理反馈 区域。
  4. 先选择老师，再选择反馈类型，最后填写反馈内容。
结果：这条反馈只会发给被选择的老师，其他老师看不到。

管理端 Step 2: 选择反馈类型

类型说明

类型什么时候用
Praise / 表扬课堂亮点、学生互动好、节奏好、老师处理得好。
Improvement / 改进建议希望老师调整节奏、反馈质量、课堂管理或作业安排。
Action Required / 需要跟进需要老师明确完成某件事，例如补充反馈、调整下节课计划。
Observation / 课堂观察记录观察，不一定要求立即行动。

选择建议

  1. 只是鼓励老师，选 Praise / 表扬。
  2. 希望老师之后注意，选 Improvement / 改进建议。
  3. 需要老师做具体动作，选 Action Required / 需要跟进。
  4. 只是留内部观察记录，选 Observation / 课堂观察。

注意

如果选择 Action Required / 需要跟进，内容里必须写清楚“老师要做什么”和“什么时候完成”，否则老师看完不知道下一步。

管理端 Step 3: 从当天课表快速关联课程

推荐模板

是否要求老师确认

默认勾选 Require teacher acknowledgement / 需要老师确认已读。如果是重要反馈、需要跟进、或管理希望确认老师已经看到，请保留勾选。如果只是普通内部记录，可以取消。

不要写得太模糊

不要只写“请注意课堂质量”。建议写成：“下节课请增加 5 分钟复盘，并在课后反馈里补充学生具体错题/薄弱点。”

管理端 Step 5: 查看最近反馈和确认状态

管理要看什么

  2. Pending ack / 待确认 表示老师还没有确认知悉。
  3. Clear / 已处理 表示不需要确认或老师已经确认。

老师收到反馈后的处理标准

老师应该做

  1. 完整阅读管理反馈，不只看标题。
  2. 如果需要确认，及时点击 确认知悉。
  3. 如果是 Action Required / 需要跟进，按反馈内容完成下一步。
  4. 如果不理解，可以微信或线下问管理确认。

老师不需要做

  1. 不需要转发给家长。
  2. 不需要在这里改课程时间。
  3. 不需要在这里处理工资或报销。
  4. 不需要回复给其他老师。

推荐回复方式

系统第一版只支持“确认知悉”，不支持在线回复。如果老师需要解释或沟通，请在线下或微信回复管理。管理如需记录后续结果，可以再发一条新的管理反馈。

特殊情况 / Special Cases

老师看不到反馈

  1. 确认老师是否登录正确账号。
  2. 确认该账号是否绑定老师档案。
  3. 确认管理发送时选择的是正确老师。
  4. 仍看不到，联系系统管理员检查账号绑定。

管理选错老师

当前第一版没有前台删除按钮。请不要继续让老师处理错误反馈，先联系系统管理员处理数据；后续版本可再增加归档/撤回功能。

反馈需要家长知道

不要直接把管理反馈截图发给家长。需要家长知道的内容，应重新整理成家长可读的课后反馈或沟通话术。

反馈和排课有关

管理反馈可以写“下节课建议……”，但真正改课、取消课、换老师，仍必须走排课或教务流程。

常见错误 / Common Mistakes

把管理反馈当家长反馈

管理反馈是内部质量管理记录，不是家长沟通文本。发给家长前必须重新整理。

没有写下一步动作

如果选择 Action Required，但没有写“做什么/什么时候做”，老师无法执行。

选错老师

发送前再次确认老师姓名和关联课程，尤其是同名或相似英文名老师。

老师只读不确认

如果要求确认，老师必须点击 Acknowledge / 确认知悉。管理端才能看到状态变化。

一句话规则

管理反馈负责“内部教学质量沟通”；家长反馈负责“对外课堂沟通”；排课/财务问题回到各自系统流程。

最终检查表 / Final Checklist

管理发送前

  • 已确认选择的是正确老师。
  • 如针对具体课堂，已关联正确课程。
  • 反馈类型选择合理。
  • 内容清楚写明观察、建议和下一步。
  • 需要确认的反馈保留了确认勾选。

老师查看后

  • 已完整阅读反馈内容。
  • 需要确认时已点击确认知悉。
  • 需要跟进时已知道下一步动作。
  • 不清楚的地方已向管理确认。
  • 没有把内部反馈直接转发给家长。

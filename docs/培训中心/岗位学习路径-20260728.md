# SGT 岗位学习路径

更新日期：2026-07-28

## 所有人共同必修

1. SGT 全系统操作流程地图：先确认任务属于哪条主流程、正确入口和最终完成结果。
2. 系统账号、权限和数据隐私。
3. 哪些操作会影响课包、扣课、财务、工资、合同或家长可见内容。
4. 工单记录、完成结果和每日交接。
5. 不确定时的停止条件和升级路径。
6. 培训数据与真实数据的使用边界。

主角色决定员工实际系统权限；兼职培训岗位只增加应学课程，不增加系统权限。员工同时承担多个岗位时，由管理者在系统使用者管理中勾选附加培训岗位。

## 教务

### 入职第一阶段

- 教务小程序完整操作。
- 教务生成家长邀请码、家长完成绑定、教务复核关系与可见权限。
- 工单、待办和每日交接。
- 学生档案和 360° 信息。
- 点名、反馈检查和家长沟通。

### 独立操作前

- 首次排课、续排、家长时间和候选时间。
- 新生首购、老生续费、合同、课包和财务门禁。
- 请假、取消、补课、换老师和异常处理。
- 学校申请服务。
- 上海新卓思学生建档及合作方结算。
- 共享课包按学生修改课程。

### 专项授权后

- 全托管完整操作。
- EduTrust 课程、SSG 合同和学生证据。
- 学校申请材料与进度管理。

## 老师

### 入职第一阶段

- 核对老师账号、关联档案和当前身份；资料未关联时停止并联系管理员。
- 从工作台按顺序处理今日课程、待点名、待反馈、交接风险、通知和签到警示。
- 老师小程序完整操作。
- 课表确认、点名和课后反馈。
- 通知与管理反馈必须阅读完整内容后确认。
- 学生历史反馈查看。
- 检查对外教师名片中的姓名、科目、授课语言、经验和介绍。

### 独立操作前

- 维护未来 30 天可上课时间，掌握单日、批量、清空当天和撤销边界。
- 回复本人排课例外：可以、不可以或提供具体替代时间；老师回复不等于正式改课。
- 老师工单：核对学生、情况、优先级和凭证，填写可核对的完成说明。
- 老师评估：只处理分配给本人且资料完整的学术问题。
- 中期报告和结课报告：以课次和反馈为证据，区分事实、判断和建议。
- 报销：先处理驳回补件和已批未付，再新建；重提不得重复建单。
- 工资：逐项核对期间、课次、课时、费率、调整和总额后确认。
- 收款资料：按所在地使用 PayNow 或 Wise，禁止提交密码或验证码。

老师岗位当前共 11 个培训模块。首次独立授课前，至少完成账号每日开工、课表点名反馈、可用时间与排课例外、报告评估、报销工资、收款资料及小程序操作的对应模块。

## 财务

### 入职第一阶段

- 财务工作台和审批提醒。
- 员工小程序登录绑定与功能边界；当前财务操作全部使用网页版，不借用管理小程序审批身份。
- 发票、付款凭证、收据和审批队列。
- 课包财务工作区和允许排课门禁。
- 老师工资单和收款资料核验。

### 独立操作前

- 报销审批。
- 企业账户开票、收款和收据。
- 交通费月结。
- 合作方结算、发票和 Credit Note。
- 财务文件中心、历史查询和附件异常修复。

## 客服与销售

- 员工小程序本人绑定与身份核对。
- 家长邀请码、绑定失败、ACTIVE 关系和可见权限排障。
- 资源录入、重复资源检查和负责人分配。
- 跟进记录、下一步和截止日期。
- 老师评估。
- 成交后转学生、合同或排课工单。
- 新加坡学校指南咨询承接。
- 资源归档、重新打开和交接。
- 销售小程序用于移动跟进；正式成交、合同、收款和建档回网页版完成。

## 管理者

- ADMIN 在培训中心查看和下载全部岗位的 33 份教材，用于跨岗位监督和验收；教材可见性不增加业务操作权限。
- 用户、角色、兼职工作台和权限。
- 为正确员工生成一次性小程序绑定码，并核对绑定状态。
- 审批提醒与财务风险。
- 资源负责人和跟进质量。
- 老师反馈、管理反馈和质量工作台。
- 全托管监督、月报审核、风险和代班。
- 家长沟通监督、通知状态和审计。
- 培训完成率、实操验收和复训。

## 建议考核

- 知识检查：80 分及格。
- 实操检查：关键步骤不得出现高风险错误。
- 首次独立操作：主管旁站或当天复核。
- 上线后 7 天：复查遗漏和错误。
- 系统重大更新：相关岗位重新确认新版本。

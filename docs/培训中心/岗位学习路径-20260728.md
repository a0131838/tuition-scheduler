# SGT 岗位学习路径

更新日期：2026-07-28

## 所有人共同必修

1. SGT 全系统操作流程地图：先确认任务属于哪条主流程、正确入口和最终完成结果。
2. 系统账号、权限和数据隐私。
3. 哪些操作会影响课包、扣课、财务、工资、合同或家长可见内容。
4. 工单记录、完成结果和每日交接。
5. 不确定时的停止条件和升级路径。
6. 培训数据与真实数据的使用边界。

主角色决定员工实际系统权限；兼职培训岗位只增加应学课程，不增加系统权限。员工同时承担多个岗位时，由管理者在系统使用者管理中勾选附加培训岗位。

## 教务

### 入职第一阶段

- 教务小程序完整操作。
- 工单、待办和每日交接。
- 学生档案和 360° 信息。
- 点名、反馈检查和家长沟通。

### 独立操作前

- 首次排课、续排、家长时间和候选时间。
- 新生首购、老生续费、合同、课包和财务门禁。
- 请假、取消、补课、换老师和异常处理。
- 学校申请服务。
- 上海新卓思学生建档及合作方结算。
- 共享课包按学生修改课程。

### 专项授权后

- 全托管完整操作。
- EduTrust 课程、SSG 合同和学生证据。
- 学校申请材料与进度管理。

## 老师

### 入职第一阶段

- 老师小程序完整操作。
- 课表确认、点名和课后反馈。
- 通知与管理反馈确认。
- 学生历史反馈查看。

### 独立操作前

- 中期报告和结课报告。
- 工资核对与收款资料。
- 报销申请。
- 可上课时间、调课和排课例外确认。
- 资源评估。

## 财务

### 入职第一阶段

- 财务工作台和审批提醒。
- 发票、付款凭证、收据和审批队列。
- 课包财务工作区和允许排课门禁。
- 老师工资单和收款资料核验。

### 独立操作前

- 报销审批。
- 企业账户开票、收款和收据。
- 交通费月结。
- 合作方结算、发票和 Credit Note。
- 财务文件中心、历史查询和附件异常修复。

## 客服与销售

- 资源录入、重复资源检查和负责人分配。
- 跟进记录、下一步和截止日期。
- 老师评估。
- 成交后转学生、合同或排课工单。
- 新加坡学校指南咨询承接。
- 资源归档、重新打开和交接。

## 管理者

- 用户、角色、兼职工作台和权限。
- 审批提醒与财务风险。
- 资源负责人和跟进质量。
- 老师反馈、管理反馈和质量工作台。
- 全托管监督、月报审核、风险和代班。
- 家长沟通监督、通知状态和审计。
- 培训完成率、实操验收和复训。

## 建议考核

- 知识检查：80 分及格。
- 实操检查：关键步骤不得出现高风险错误。
- 首次独立操作：主管旁站或当天复核。
- 上线后 7 天：复查遗漏和错误。
- 系统重大更新：相关岗位重新确认新版本。

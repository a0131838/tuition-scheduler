中文版 · 完整步骤总览

共享课包按学生修改课程

1搜索课包归属学生，核对课包、共享学生、课程和余额。
2点击 Edit / 编辑，找到修改一名共享课包学生未来课程。
3选择要修改的学生、原课程、新课程并填写原因。
4核对预览中的未来一对一课次数量及不会修改的课次，再决定是否保存。
5保存后核对所选学生的未来课次、共享课包余额及其他学生课次。

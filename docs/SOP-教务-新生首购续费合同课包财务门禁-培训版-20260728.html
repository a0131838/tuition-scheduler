MUST KNOW / 先记住

开始操作前的强制规则

  1. 新生首购与老生续费必须走各自入口。
  2. 不能重复创建家长资料、合同或发票。
  3. 直接收费课包以发票审批作为第一排课门禁。
  4. 付款凭证和收据继续由财务闭环，不等于教务可跳过审批。
页面、权限或状态与 SOP 不一致时，停止会影响课包、财务、工资、合同、家长可见内容或真实课次的操作，并向主管确认。

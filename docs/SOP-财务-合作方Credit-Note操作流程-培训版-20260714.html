合作方 Credit Note / 贷项通知单操作流程

适用于已开具合作方发票后，因来源文件更正、服务未提供、部分费用减免或其他已确认原因，需要以独立追踪编号减少原发票金额的情况。

适用人员Finance / 财务
系统路径Partner Settlement → Credit Notes
版本日期2026-07-14

一句话流程

找到原发票 → 创建 Credit Note 草稿 → 填地址、原因、项目金额及 GST → 预览核对 → 勾选确认 → 正式开具。
最重要：不要修改或删除原发票；不要在未核对来源文件、客户地址、金额和 GST 前点击 Issue / 正式开具。
SGT Manage · Finance SOP · Partner Credit Note · Page 1

先记住：5 条必须遵守的规则

  1. Credit Note 是独立凭证，不会修改、覆盖或删除原发票。
  2. DRAFT 只预留可调整金额，不会减少 Adjusted net / 调整后净额。
  3. ISSUED 且未作废的 Credit Note，才会计入已开 Credit 并减少调整后净额。
  4. VOID 会永久保留在历史中，但不再减少原发票金额。
  5. 原发票已有收据时，Credit Note 不会自动修改收据；退款或抵扣下张发票必须由财务另行记录。

状态和金额影响

状态可以做什么是否影响调整后净额是否可以删除历史
DRAFT / 草稿编辑、预览、正式开具或作废否否，只能作废
ISSUED / 已正式开具导出 PDF、PDF + Seal，必要时作废是否
VOID / 已作废查看历史和作废原因否否
权限：创建、更新、正式开具、作废和下载 Credit Note 仅限 Finance 和超级管理员。

步骤 1：进入 Partner Settlement

Finance Workspace
操作：登录财务账号，在左侧 Finance Workspace 点击 Partner Settlement / 合作方结算。
图 1：Credit Note 位于合作方结算账单中心，不在学生课包发票或企业账户发票页面。
SGT Manage · Finance SOP · Open Partner Settlement · Page 4

步骤 2：从原发票创建 Credit Note

Invoices / 发票
操作：打开 Invoices / 发票，找到需要调整的原发票；先核对原金额、已开 Credit 和调整后净额，再点击该行的 Create / 创建。
图 2：Credit Note 必须从正确的原发票开始。系统会把原发票号、日期、客户和项目带入新草稿。
不要：不要为了改金额删除原发票，也不要重新开一张负数发票。
SGT Manage · Finance SOP · Select original invoice · Page 5

步骤 3：确认合作方、模式和 Credit Notes 页签

Partner · Mode · Month
操作：选择合作方、业务模式和月份后点击 Apply / 应用，再进入 Credit Notes / 贷项通知单。
图 3：新东方线上课包结算使用 Online: Package End / 线上：课包结束。其他合作方应按原发票所属模式选择。
看不到原发票：先检查合作方和 Mode 是否与原发票一致；线上 Package End 发票通常不依赖月份筛选。
SGT Manage · Finance SOP · Filters and tab · Page 6

步骤 4：再次选择并核对原发票

Original invoice
操作：在 Original invoice / 原发票 下拉框选择正确号码，点击 Open / 打开，核对四个金额卡片。
图 4：新东方案例原发票为 RGT-202606-0019，原金额 SGD 18,540；草稿阶段已正式开具 Credit 仍为 0。
停止并确认：发票号、客户或原金额与来源文件不一致时，不要继续填写。
SGT Manage · Finance SOP · Confirm invoice · Page 7

步骤 5：填写客户地址和调整原因

Required before issue
操作：填写来源文件上的客户正式地址；在 Reason for credit / 调整原因 中写清月份、差异原因、依据文件及必要的内部说明。
图 5：客户地址在正式开具前必填。原因必须让复核人能够从 Credit Note 回到具体来源文件。
推荐原因写法：
Correction of April 2026 service amount based on revised source document. Original April line SGD 4,500; corrected line SGD 4,230; credit SGD 270.
SGT Manage · Finance SOP · Address and reason · Page 8

步骤 6：填写项目 Credit 金额和 GST

Line-level credit
操作：只在需要调整的原发票项目填写 Credit total / 本次 Credit 金额；在 GST credited / 其中 GST 填入本次冲减中属于 GST 的金额。确认后点击 Save draft / 保存草稿。
图 6：新东方案例只调整 2026 年 4 月项目 SGD 270，GST 为 0；其他月份保持 0。
GST 不是自动计算：系统默认 0。必须根据原发票和来源文件确认；不确定时停止并请财务负责人复核。
SGT Manage · Finance SOP · Amount and GST · Page 9

步骤 7：编辑并复核草稿

Edit draft / Update draft
操作：保存后先点 Edit draft / 编辑草稿，逐项检查日期、客户、地址、原因、项目、Credit 总额和 GST；有修改时点击 Update draft / 更新草稿。
图 7：系统会阻止单行或累计 Credit 超过原项目可调整余额，也会阻止总 Credit 超过原发票金额。
双人复核建议：制单人完成草稿后，由另一位财务人员对照原发票与修订来源文件复核，再正式开具。
SGT Manage · Finance SOP · Review draft · Page 10

步骤 8：预览、正式开具或作废

Preview · Issue · Void
正式开具：先点击 Preview / 预览 检查 PDF；确认无误后勾选 Source, address, amount and GST verified，再点击 Issue / 正式开具。
图 8：DRAFT 不减少调整后净额。ISSUED 后才显示在 Issued credits，并可导出正式 PDF 或 PDF + Seal。
需要作废时：在 Void reason / 作废原因 中写清原因，再点击 Void / 作废。作废不是删除，历史会继续保留。
SGT Manage · Finance SOP · Preview issue void · Page 11

PDF 预览：正式开具前要看什么

DRAFT PREVIEW
核对顺序：Credit Note No. → Original Invoice → Customer Name/Address → Reason → 项目金额/GST → This credit note → Adjusted invoice total。
图 9：草稿 PDF 会显示 DRAFT PREVIEW - NOT ISSUED，不会带公司章。只有 ISSUED 后才能使用 PDF + Seal。
任何字段不正确：关闭 PDF，回到历史行点击 Edit draft / 编辑草稿；不要先 Issue 再修改。
SGT Manage · Finance SOP · PDF preview review · Page 12

已正式开具后的后续处理

原发票尚未收款

以 Adjusted net / 调整后净额 作为剩余应收参考；将正式 Credit Note PDF 与修订来源文件一并归档。

原发票已经有收据

系统不会自动改收据。财务必须明确记录：退款给客户，或抵扣下一张发票，并保存审批与付款证据。

需要发送给客户

使用 Export PDF；需要公司章时，仅对 ISSUED 记录使用 PDF + Seal。

发现正式凭证有误

不要改数据库或删除记录。输入完整作废原因并 Void，再根据正确来源文件重新创建新的 Credit Note。

归档材料

  1. 原发票 PDF。
  2. 修订前和修订后的来源文件。
  3. 正式 Credit Note PDF。
  4. 退款或抵扣后续发票的审批、付款及沟通证据。

新东方 SGD 270 示例

原发票RGT-202606-0019原发票总额SGD 18,540.00
调整项目2026 年 4 月已上课学生名单统计原项目金额SGD 4,500.00
修订项目金额SGD 4,230.00Credit 总额SGD 270.00
GST creditedSGD 0.00调整后发票净额SGD 18,270.00

制单时填写

  • Customer address：以客户正式资料或修订来源文件为准。
  • Reason：写明 2026 年 4 月来源文件修订，原项目 SGD 4,500，修订后 SGD 4,230。
  • 4 月项目 Credit total：270.00。
  • GST credited：0.00。
  • 3 月和 5 月项目：保持 0。
本例只说明系统操作：正式开具前仍需财务再次核对客户地址、修订来源文件和会计处理。

常见问题和处理方式

情况原因正确处理
找不到原发票合作方或 Mode 不匹配回到筛选区，按原发票所属合作方和模式重新 Apply。
无法保存草稿没有填写任何 Credit 金额，或原因少于 5 个字符至少在一个正确项目填入大于 0 的金额，并写清原因。
提示超过可调整余额本次金额加已有草稿/正式 Credit 超过原项目检查历史记录，不要重复冲减。
无法正式开具地址未填，或未勾选核对确认补全客户地址并完成四项复核。
原发票已有收据款项已收但后续发生调整Credit Note 正常开具；退款或抵扣下一张发票另行记录。
正式开具后发现错误正式凭证不可直接编辑填写作废原因并 Void，再创建正确的新 Credit Note。

正式开具前最终检查

  • □ 原发票号、客户、日期和原金额正确。
  • □ 客户正式地址已填写。
  • □ 调整原因能够对应修订来源文件。
  • □ 只调整正确的发票项目，金额没有重复。
  • □ GST 处理已确认。
  • □ Preview PDF 无错误。
  • □ 已决定后续是退款还是抵扣下一张发票。

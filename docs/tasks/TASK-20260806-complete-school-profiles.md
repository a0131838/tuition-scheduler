# TASK-20260806：新加坡学校指南完整学校档案

## 目标

将学校指南从少数重点学校展示扩展为现有完整目录：全部 43 条学校/校区记录都提供中英文名称、基础择校档案、资料更新时间和复核周期；官方公开资料充足的学校进一步提供在校规模、历年成绩和大学去向。

## 产品边界

- 家长页面不展示学校电话或学校官网跳转，主要操作保留为查看档案、申请评估和微信咨询。
- 学校官网地址和官方来源继续保留在服务端资料层，供内部核查和定期更新，不在消费者页面露出。
- 不补写学校未公开的数据，不以行业传闻、论坛信息或估算值代替官方资料。
- `学校未公开`表示当前官方资料未找到或未稳定公开，不表示学校没有相关成果。
- 本次不修改员工、家长登录，不修改排课、课包、余额、出勤、工资、续费、财务、工单和权限。

## 实现范围

- 43 条学校/校区全部增加中文名和英文名搜索、展示。
- 所有记录增加公开资料更新时间、更新频率和下次复核日期。
- 全部记录保留招生、课程、费用等原有基础档案，并在学校详情中统一为可展开结构。
- SAS、德威、北伦敦、东陵信托及 UWCSEA 校区根据已核实官方资料增加学生规模、历年 IB 表现或大学去向。
- 学校详情重做为移动端档案页：身份、四项快照、学校概况、校园规模、招生与课程、学术表现、大学去向、费用和下一次复核。
- 家长咨询和测评码申请取消电话字段，微信号改为必填；隐私说明同步更新。
- Web 与微信小程序使用同一套学校资料模型，搜索和缺失数据表达一致。

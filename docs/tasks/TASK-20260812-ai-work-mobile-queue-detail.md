# TASK-20260812：AI今日工作移动端列表与详情

## 目标

解决手机端点击工单后必须继续向下翻找详情的问题，并让页面配色、文字和操作方式与现有橙色小程序一致。

## 修改

- 默认只显示紧凑的待办列表，不再把所有待办与一张详情卡纵向堆在同一页面。
- 点击待办后，页面回到顶部并只显示这一张工单的完整详情和确认操作。
- 详情页提供“返回待办”，返回后恢复原列表滚动位置。
- `NEW_SCHEDULE`、`RESCHEDULE`、`CANCEL_LESSON`、`SUPPLEMENTARY`、`CHANGE_TEACHER`等标签改为中文业务名称。
- 去掉大块深绿色说明卡，主按钮、状态强调和日历事件统一为现有小程序橙色`#EC5E0A`体系。
- 不修改AI识别、正式排课、冲突检查、扣课时、工资、财务或通知逻辑。

## 员工操作影响

- 岗位：Eva教务；Emily仍负责原工单录入。
- 修改前：点击列表后还要向下寻找详情，任务多时容易误以为没有打开。
- 修改后：点击一项立即进入该工单详情；核对或处理完成后返回原列表位置。
- 普通流程人工决定：仍为一次最终确认，不增加按钮和步骤。
- 正式系统影响：仅小程序页面展示和导航状态；正式数据0修改。

## 界面复杂度核对

- 一个屏幕只承担一个任务：列表选工单，详情处理工单。
- 列表只保留学生、中文类型、下一步、截止时间和进入箭头。
- 详情保留原来的必要决定、方案预览、月历和一次确认。
- 英文流程代码不再直接展示给员工。

- 上传新的微信开发版后，在iPhone尺寸真机检查：点开首项立即见详情、返回恢复位置、中文标签无截断、橙色一致。

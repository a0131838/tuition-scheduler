# TASK-20260728-multi-role-operation-coverage

## Context

员工可能同时承担教务、财务、销售、客服或老师培训责任；原培训中心只按一个主角色分配课程。同时，现有 SOP 覆盖核心高风险流程，但缺少系统全部可见页面到业务流程的可审计映射。

## Change

- 新增独立的附加培训岗位，不改变账号主角色和系统操作权限。
- 在系统使用者管理中增加培训岗位勾选和保存。
- 培训中心合并主角色及附加培训岗位的课程，去重后展示。
- 所有阅读、测验、实操和受保护 PDF 均按合并后的培训岗位校验。
- 新增 `/training/coverage` 主管覆盖图。
- 将 144 个网页页面与 54 个微信小程序页面归入 16 条按业务结果组织的主操作流程，自动测试保证 0 个未归类入口。
- 新增 19 页《SGT 全系统操作流程地图》PDF，并作为所有员工共同必修。

## Non-goals

- 附加培训岗位不授予 Admin、Finance、Sales、CS 或 Teacher 的业务页面权限。
- 不修改排课、点名、扣课、合同、课包、发票、收据、工资、报销、结算或家长可见逻辑。
- 不为每个查看页、历史页或导出页重复制作一份独立 PDF；相关页面归入同一完整业务结果流程。

## Verification

- Prisma format/generate。
- 培训岗位、权限隔离、迁移安全和全部可见页面映射测试。
- TypeScript。
- 117 项后端完整测试。
- 228 页面生产构建。
- 流程地图 PDF 共 19 页，关键文字提取通过，全页 contact sheet 无裁切、重叠或空白页。

## Risk

中等且隔离在培训分配。主要风险是管理者把“培训岗位”误解为“系统权限”；页面、PDF 和文档均明确说明两者独立，API 也只写入独立培训岗位表。

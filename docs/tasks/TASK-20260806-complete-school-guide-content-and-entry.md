# TASK-20260806：学校指南全量详情、申请资料与扫码入口

## Context

上一版已经把学校目录整理为六个并列大类和34个国际学校品牌，但部分国际学校只有名称，政府、学前、专上与特殊教育分类仍停留在摘要。旧体验版或指定登录路径生成的二维码还会把消费者送到家长登录，不符合“先提供内容、需要时再进入私域”的产品目标。

## Change

- 接入MOE 2026开放数据：学校基本资料337条、科目14,719条、MOE Programme 80条、Distinctive Programme 284条；在产品中形成326个政府学校档案及11个JC/高中档案。
- 补齐34/34国际学校品牌的课程、招生、评估及校区结构；本地自主学校、艺术/体育专科学校和学前品牌按真实申请路线展示。
- 增加学前、私立、Madrasah、PEI、Poly、ITE、艺术院校、六所自治大学及25所SPED档案。
- 增加18条申请路径，展示步骤、考试/评估内容、材料和注意事项。
- 生成14份博思原创PDF练习或申请清单，明确不是MOE或学校真题、不预测正式考试。
- Web与Mini Program新增非国际学校详情页面，并把申请路径和PDF资料接入学校详情。
- Mini Program继续以学校指南为首个页面；登录页分享统一回公开指南；`entry=assessment`直接进入学术评估。

## Data rules

- 政府学校结构化字段来自MOE/data.gov.sg 2026开放数据。
- SPED学校和申请规则来自MOE公开页面；学前与运营商规则来自ECDA。
- 国际学校仅记录学校或主管机构公开内容；未公开的统一题型不猜测。
- 下载材料为博思原创准备材料，不能标记为官方样题、真题或预测题。
- 页面不展示电话号码，不依赖家长复制学校官网链接。

## Non-goals

- 不修改家长或员工的认证API、账号绑定与权限。
- 不修改排课、课包、余额、出勤、工资、续费、财务、工单或数据库结构。
- 旧二维码编码的页面路径无法被程序改写，发布后必须重新生成二维码。

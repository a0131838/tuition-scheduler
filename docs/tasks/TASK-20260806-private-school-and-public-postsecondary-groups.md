# TASK-20260806 私立高校归类与公立升学二级导航

## 目标

让家长按真实择校思路区分私立教育与公立升学，避免私立大学、JC、理工学院和自治大学混在同一长列表；同时补齐辅仁国际学校及家长常咨询的八所私立高等教育档案。

## 完成范围

- 所有私立高等教育档案迁入`私立与特色学校`。
- 私立栏目新增`私立中学 / 热门私立高校 / 其他私立高校 / 回教与特色`二级筛选。
- 公立栏目改名为`公立高中与大学`，新增`JC / MI / 理工学院 / ITE / 艺术院校 / 自治大学`二级筛选。
- 热门八所为JCU、Curtin、SIM GE、Kaplan、PSB、MDIS、SP Jain和LSBF；该名称表示常见咨询清单，不表示官方排名。
- 辅仁国际学校增加课程、入学测试、面试、国际学生步骤与付款核对信息。
- 网页、小程序和公开API使用同一分类规则，小程序缓存版本更新为`r337`。

## 明确不改

- 不修改数据库。
- 不修改家长或员工登录、权限和工作台。
- 不修改课程、排课、出勤、课包、余额、工资、续费、财务或工单。
- 不把机构层面的注册或EduTrust状态解释为课程排名、就业保证或所有课程认可。

## 验证标准

- 八所热门私立高校全部属于`private-specialist`，且全部落入`private-higher`二级分类。
- `postsecondary`中不存在任何`热门8所`档案。
- 公立JC/MI、理工、ITE、艺术院校和自治大学每组均有可打开档案。
- 网页与小程序可切换二级分类，搜索、数量和分页均以当前分类为准。
- 专项测试、TypeScript、后端回归、小程序发布审计和生产构建通过。
- 发布后线上API版本为`2026-08-06-r337`，微信开发版为`1.0.34`。

# 工单已有结果核验与完成状态优化

日期：2026年10月8日，新加坡时间。版本 r479。

## 问题与范围

用户提供9月13、17、19、27日工单处理材料，并授权按分析建议修改并发布服务器。处理人员经常先响应家长并更新课程，再补工单。旧版为防止无证据关单隐藏了课程动作的整单完成模式，却在“实际工作已经处理过”区域保留 NOT_REQUIRED，误选会把实际完成工作记成取消。

## 最终改动

原工单首屏提供“已在课表处理？核验并完成”，每个动作显示原课当前状态、目标时间或老师。新增课程列出同一学生历史及未来课程，匹配提示不自动勾选、不代表已经完成；教务核对后提交。显示已执行、无需执行和剩余动作数。多节缺少结果时保留待办，取消加补课继续分项追踪。

撤回入口和结果核验分开，撤回用于重复录单、家长撤回或需求失效。下方正式执行区只链接到首屏核验，避免重复表单。日期、科目、单节时长、节数及总时长差异包含具体要求和实际值，变更仍须确认依据。

沿用既有服务端事务、权限、学生及原课程范围校验、考勤与实际净课时流水核验。直接核验已取消课不会恢复或再次取消。历史已取消工单不批量改状态；没有原课程或目标资料时需补齐后核验，不用备注冒充证据。中文、英文及双语使用原语言偏好。

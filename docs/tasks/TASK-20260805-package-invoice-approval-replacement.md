# TASK — Package invoice approval replacement safety

## Goal

Keep a package's finance approval and scheduling gate attached to the invoice generated by its current signed contract, including the correction flow where an earlier unreceipted draft invoice was deleted.

## Problem found during E2E

The `赵测试2` controlled test deleted an initial invoice draft before generating and signing the corrected Full Care contract. The deleted invoice's pending manager approval remained. Contract signing then reused that package-level approval even though it referenced a different invoice, leaving the new invoice without a manager approval action.

## Implemented controls

- Reuse an approval only when its `invoiceId` exactly matches the signed-contract invoice.
- Remove stale `PENDING_MANAGER` approvals before creating the current invoice approval.
- Remove an invoice's pending approval when that unreceipted draft is deleted.
- Preserve approved and rejected approval history.
- Record the number of removed pending approvals in the invoice-deletion audit metadata.

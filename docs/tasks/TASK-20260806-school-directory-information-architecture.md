# TASK-20260806：找学校目录重组与重复学校合并

## 目标

把“找学校”从纵向堆叠的官方链接目录改为家长可直接使用的学校索引：六个大类并列，进入大类后再看小类；国际学校不再位于页面底部；同一品牌的重复、校区和学段记录合并为一个学校入口。

## 数据处理

- 保留 43 条底层学校/校区记录及其来源，不删除审计证据。
- 消费者目录合并为 34 个学校品牌。
- 完全重复：Global Indian International School、One World International School 各合并为一条。
- 品牌/校区合并：EtonHouse 4 条、Odyssey 4 条、UWCSEA 2 条分别合并为一个入口。
- ACS International 与 ACS Independent、SJI 与 SJI International 等实际不同学校继续分开。
- 所有旧校区 slug 继续解析到合并后的品牌详情，已有收藏和分享链接不失效。

## 新目录结构

六个并列大类：

1. 国际学校；
2. 政府学校；
3. 幼儿园与学前；
4. 私立与特色学校；
5. 高中与专上；
6. 特殊教育支持。

国际学校默认展示前 12 所，可按第一梯队、IB、英式、美式和学前筛选，也可展开全部 34 所。其他大类直接显示内部小类及官方资料摘要，不再复制或跳转官网。

## 文案和界面

- 删除“复制官方链接”、主管机构标签和长篇来源说明。
- 删除“尚未完成逐校核实”等内部工作话术。
- 列表只显示中英文校名、课程、第一梯队和校区数量；完整内容进入详情查看。
- 同品牌详情增加“校区与学段”，并保留原有招生、课程、费用、成绩和大学去向。
- 无公开数据统一使用短文案，不重复解释资料原则。
- Web 和微信小程序使用同一套分类与品牌聚合数据。

## 安全边界

本次只修改公开学校指南及其本地收藏/比较展示。不修改登录、排课、课程、课包、余额、出勤、工资、续费、财务、工单、权限或数据库结构。

- TypeScript、Mini Program JavaScript 语法、66 页发布审计。

- 政府学校分类切换、旧 UWCSEA East 链接合并和外部链接缺失检查。
- 完整后端测试和生产构建在发布前执行。

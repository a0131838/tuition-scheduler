# TASK-20260807-school-curriculum-classification

## Context

国际学校页面仍有“第一梯队”“待分梯队”等内部编辑文案。主课程筛选直接使用全部标签，导致同时提供IB和A Level的学校既出现在IB，也出现在“英式 / A Level”；更严重的是旧标签会扫描介绍全文，早稻田涩谷因说明中出现“与英美IB学校不同”而被误判为IB。

## Change

- 家长端网页与小程序彻底移除“第一梯队、待分梯队、IB重点、优质非IB”等编辑标签。
- 课程标签只读取结构化课程、招生课程、公开成绩课程及课程详情，不再从普通介绍文字猜测。
- 每所学校建立唯一主课程分类：IB优先，其次英式/Cambridge、美式/AP、其他课程；多课程学校仍在详情中完整展示全部课程。
- Tanglin等IB+A Level学校只进入IB主栏目；SAS进入美式/AP；Brighton进入英式/Cambridge；早稻田涩谷回到其他课程。
- 小程序目录缓存版本和公开数据版本更新为`2026-08-07-r349`。

## Non-goals

- 不删除学校的真实第二课程或高中课程路径。
- 不改变智能选校评分、入学难度、费用、成绩、准证、登录或任何员工业务流程。

## Verification

- 自动检查66个国际学校品牌均只有一个主课程分类。
- 自动检查英式/Cambridge栏目不含任何IB主课程学校，美式/AP栏目不含IB或英式主课程学校。
- 自动检查网页和小程序家长可见文件不再出现梯队文案。
- 运行学校指南测试、后端回归、TypeScript、生产构建、小程序审计与原生JavaScript语法检查。

完成结果：66项学校指南测试、174项后端回归、TypeScript、67页小程序审计、全部小程序JavaScript语法与243页生产构建通过；390×844手机视口实际点击验证通过。最终分类为IB 23所、英式/Cambridge 22所、美式/AP 5所、其他课程16所。

## Risk

低。仅调整公开学校指南的课程归类、标签和文案，不更改学校原始资料及已登录业务。

# TASK-20260807-school-guide-home-visual-anchor

## Context

学校指南首页标题区设置了`430rpx`固定最小高度，并通过`justify-content:flex-end`把内容沉底，造成微信原生导航栏下方出现大块无功能空白。热门学校只有单个汉字标志，辨识度和视觉完成度不足。

## Change

- 删除首页标题区固定高度，内容从顶部开始排布并缩短上下间距。
- 将网格背景改为克制的暖色编辑式背景，增加小型`SG`产品标志。
- 搜索框紧跟标题并增加轻微层次，不再悬在首屏底部。
- 八所热门学校使用固定英文缩写、独立克制配色和圆形识别标志。
- 首页保留本地校徽图片槽位；未获得授权或图片缺失时自动使用文字标志。
- 目录缓存版本升级为`2026-08-07-r343`。

- 不修改家长/员工登录、教学、排课、课包、财务、工资、工单或消息。

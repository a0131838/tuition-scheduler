# 提前续费后分配下一期结课报告

1. Jessika 在管理端打开「结课报告 → 管理学习期次」，搜索学生，选择对应课程。按续费入账日期和新增课时找到本次续费。
2. 点击「分配本期报告」，选择负责老师，保留「为本期新建报告」，点击「分配并打开报告」。同一期、同一老师重复操作会打开已有报告。
3. 老师在「结课报告」打开对应续费期，可以先保存草稿。学生仍在使用上一期课时时，新期显示「等待本期实际出勤」。本期出现可匹配的出勤后，系统显示首节至最近一节的实际教学日期。老师提交时保存当次报告的出勤范围和课时。
4. 出现「待 Eva 确认的学习期分界」时，Eva 在同一入口打开该条记录，核对首节及本次报告覆盖的末节实际出勤，点击「确认教学分界」。常规续费无需手填日期。
5. 老师提交后，Jessika 在结课报告的审核与交付页核对家长版，批准后下载 PDF。报告审核和课包余额分别处理。

日期推算只读取续费入账、扣课流水和实际出勤。分期按入账顺序匹配已经使用的分钟。课次跨越两笔课时、历史流水无法对齐等情况由 Eva 核实。测试使用隔离数据库，覆盖提前分配、重复操作、上一期未用完、实际出勤、跨期人工确认、网页和小程序提交、审核及 PDF 下载，并比对历史报告和扣课记录。

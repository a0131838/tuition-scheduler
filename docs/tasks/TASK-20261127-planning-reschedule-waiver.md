# 排课中调整，无需补发

1. 网页打开「家长沟通与通知 → 沟通与提醒工作台 → 课程变更补发」。员工小程序打开教务沟通工作台的「课程变更补发」，点对应记录的「处理」。
2. 核对学生、日期和新旧时间。由任务当前负责人 Eva 或 Emily 操作。如由同事负责，可按原流程转交或接手。
3. 仅限内部排课调整，确认旧时间没有通过群聊、私聊、电话或其他方式告知家长，家长也没有按旧时间安排接送时，点「排课中调整，无需补发」，阅读提示后确认。无须截图或另填备注。
4. 关闭后，任务退出待办并停止提醒。「全部记录」保留「无需发送」、原因和操作日志。如后续再改课，按新任务处理。
5. 家长已获知旧时间或无法确认时，继续向原群发送最新安排。已登记发群的，按实际确认渠道登记接送人回复。已有本次发送截图或同课次同家庭的发送记录时，系统保留原跟进流程。

后端在同一事务内校验教务身份、负责人、课表版本和发送记录，记录关闭原因与操作人。网页和员工端读取同一操作权限。系统无法推断线下电话或个人微信沟通，需由负责人如实确认。该操作仅处理所选家庭的本条沟通任务。生产发布与微信客户端渠道分别以各自发布回执为准。

# TASK-20260806-school-guide-readable-ui

## Context

家长反馈学校指南首页和详情页文字密度过高、辅助字号偏小，顶部标点化标题和底部字符图标也不够专业。更新时间、下次复核和资料来源不应抢占主要阅读位置。

## Change

- 首页改为大标题、搜索入口和四个核心任务：找学校、智能选校、入学考试、英文测评。
- 热门学校改为横向浏览，首页不再同时展示中英文名称和解释段落。
- 底部导航删除 `⌂` / `⌕` / `◎` / `◇` 字符，改为大字号文字导航和活动指示线。
- 全局提高辅助文字、列表说明、表单标签和底部导航字号。
- 学校概览、招生详情、私立高教合作院校专业、申请规则和材料默认收起，家长按需展开。
- 学校更新日期、下次复核、机构资料来源和测评边界说明统一放在页面底部弱化显示。

## Non-goals

- 不删除学校、费用、成绩、合作院校、专业或申请路径资料。
- 不修改家长登录、员工登录、评估计分、教学、排课、课包、财务、工资、工单或消息逻辑。
- 网页版本的学校指南界面不在本次视觉范围。

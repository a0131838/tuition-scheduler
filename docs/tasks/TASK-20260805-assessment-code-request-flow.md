# TASK-20260805 入学准备度测评码申请闭环

## 目标

让家长在“新加坡学校指南”小程序内主动申请评估码，并把申请稳定转入私域联系、发码、学生测评、老师复核、人工解读和后续跟进。入口必须简单，员工必须知道下一步做什么，老师不得看到咨询和学生经营信息。

## 已确认业务规则

- 新申请默认负责人：`zhao hongwei`（系统账号 `zhaohongwei0880@gmail.com`）。
- 家长必须留下微信号或电话；系统不自动公开发码。
- ADMIN、CS、SALES可以处理申请和发码；TEACHER只处理测评复核。
- 评估码默认14天有效、一次使用；完整码只在生成响应中显示一次。
- 测评用于GT教育咨询和准备建议，不是学校、MOE或AEIS官方成绩，不预测录取。
- 不修改课程、排课、课包、余额、出勤、财务、工资、续费和工单业务。

## 家长流程

1. 进入“学校指南 → 入学准备度测评”。
2. 选择“申请评估码”，填写家长称呼、学生昵称、年龄段、当前年级、目标方向、主要需求、联系方式和希望测试日期。
3. 同意资料使用后提交；原设备保存不可猜测的申请查看凭证。
4. 在“查看申请进度”查看待联系、已联系、可发码、测评中、待复核、报告完成和已解读。
5. 顾问发码后可从申请页直接开始，也可输入收到的一次性评估码。
6. 完成30–45分钟测评；开放题由老师复核；报告完成后预约人工解读。

## 员工流程

1. 员工测评工作台显示开放申请、待老师复核和最近完成数量。
2. 进入评估码申请队列，按“待联系 → 已联系 → 可发码 → 已发码”处理。
3. 申请详情集中展示联系方式、年龄年级、目标、需求、期望日期和对应资源编号。
4. 联系家长后可一键确认资料并发码，复制评估码或完整微信通知。
5. 学生提交后，老师在原有复核页面评分；管理/教务完成家长解读并关闭申请。
6. 每次状态变更、发码、撤销、开始、提交和复核继续写入审计日志与资源跟进记录。

## 安全与异常

- 公开申请凭证只保存哈希；仅凭相同联系方式重复提交不会返回原学生资料、申请编号或新凭证。
- 原设备持有正确凭证时可更新同一开放申请。
- 未使用的关联评估码撤销后，申请返回“可发码”，可以安全重发。
- 已使用评估码不能撤销；评分更正继续走原有纠正日志。
- 年龄段与目标路径不匹配、低龄DSA未配置等情况在提交或开始前阻断。

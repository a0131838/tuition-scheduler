# TASK-20260807-school-priority-visa-copy

## Context

国际学校“全部”列表沿用课程分组顺序，导致属于美式课程的SAS没有和其他第一梯队学校连续出现；同一课程内大量学校同分后按英文名排序，家长无法获得稳定的浏览优先级。每所学校又无条件展示统一的Student’s Pass书面确认兜底语，重复、占空间且没有帮助家长决策。

## Change

- 为60所国际学校建立唯一、稳定的消费者浏览顺序，五所第一梯队连续置顶。
- IB、英式/Cambridge、美式/AP和其他课程筛选沿用同一顺序，各分类优先展示更成熟、竞争度更高或家长更常比较的学校。
- 排序只影响目录浏览，不修改智能选校评分、冲刺/匹配/稳妥判断或录取结论。
- 网页和小程序列表不再显示通用Student’s Pass书面确认兜底语。
- 学校详情摘要以“申请判断”替代“学生准证”；申请页只在学校明确要求DP、LTVP、PR等长期准证时显示“准证限制”。
- 数据及小程序缓存版本更新为`2026-08-07-r351`。

## Non-goals

- 浏览先后不是官方排名，也不构成学校质量、录取或签证保证。
- 不删除底层Student’s Pass研究字段，后续官方资格变化仍可复核。
- 不修改评估推荐、登录、教学、排课、课包、财务、工资、工单、通知、权限或数据库。

## Verification

- 68项学校指南测试通过，自动锁定整体前五和四个课程筛选的首位学校。
- 174项后端回归、TypeScript、小程序原生JavaScript语法、67页发布审计及243页生产构建通过。
- 390×844浏览器检查确认五所第一梯队连续置顶、列表不再重复显示通用准证提示、详情摘要显示“申请判断”且成绩升学仍为默认页。

## Risk

低。变更只影响公开指南的浏览顺序和提示文案；排序属于博思编辑判断，应定期结合学校成绩、课程稳定性、申请竞争度和家长实际需求复核。

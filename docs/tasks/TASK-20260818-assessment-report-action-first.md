# TASK-20260818：测评报告统一为“结果—提升—联系老师”

## 目标

把国际学校英语、AEIS 小学与 AEIS 中学的家长端完成报告统一为三步：先看结果，再看 8 周提升计划，最后联系规划老师。技术证据继续保留，但默认折叠，不再让家长先阅读可信度、题量、逐技能长表和重复免责声明。

## 实现

- 所有新报告由服务端生成三阶段提升计划：第 1–2 周补稳首要薄弱项，第 3–6 周强化次要薄弱项，第 7–8 周计时模拟与平行卷复测。
- 已保存的旧报告在小程序展示时按既有薄弱项生成同样的三阶段计划，无需重测，也不重写历史报告。
- 完成页固定显示“测评结果”“接下来怎么提高”“制定个人学习方案”三部分。
- CEFR、分项证据、覆盖题量、与上次比较和测评边界移入“查看详细分析”，默认收起。
- 未测能力只在详细分析中标记“本轮未测”，不在结果主页面显示为 0 分。
- 联系规划老师时自动带入学生代码、年龄段、分项成绩和优先提升项，减少家长重复描述。
- 等待写作复核页只说明结果正在复核，并保留平行卷复测入口。

## 安全边界

- 只修改学校指南测评报告生成和家长小程序展示。
- 不重算或覆盖旧报告，不修改正式学生、排课、课包、考勤、工资、财务、工单、登录、权限或消息流程。
- 规划老师入口仍由家长主动点击，不自动发送真实消息。

# 员工本人工资单 PDF 下载权限修复

日期：2026年10月19日，新加坡时间。版本 r483。

## 原因与授权范围

Jessika在员工自助查看自己的已批准工资单，点击PDF后收到公司财务权限不足。生产只读核查确认该工资单属于本人且为DIRECTOR_APPROVED，其会话带有效operations受限标记。现有PDF接口允许员工读取本人DIRECTOR_APPROVED或PAID工资单，但中间件白名单未放行该路径，请求在进入本人校验前即403。

用户授权按建议修改，并要求其他东西别动。唯一业务代码修改是lib/operations-admin-access.ts增加精确的/api/hr/payslips/单个ID/pdf路径匹配。未改PDF接口、工资计算、审批、金额、角色、工作区或数据。

- 最终生产构建通过，含类型检查及266个静态页面。隔离HTTP验收通过：本人已批准及已付工资单200且文件头为%PDF-，他人工资单403、草稿及作废403、匿名401、POST405，公司财务API仍403。两次成功下载产生两条原有下载审计，工资单各字段、课时流水及通知队列保持原样。虚构测试记录已清理。

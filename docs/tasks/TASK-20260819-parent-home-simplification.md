# TASK-20260819 家长端首页二次精简

## 目标

把家长端首页从“信息报告页”改为“行动入口页”。家长打开后只需要判断两件事：现在是否有事情要处理，以及下一步应点击哪里。

## 本次范围

- 首页顶部只保留学生姓名、服务类型和切换孩子入口。
- 同一时间最多展示一个需要家长处理的事项。
- 仅在存在已确认课程时展示下一节课；不再展示空课表说明。
- 首页只保留课表、服务进展、联系团队三个高频入口；无工单权限时第三个入口显示我的资料。
- 移除首页的大型状态说明、最新进展长文和本周数据；原数据仍在进展、课表和我的页面中。

## 安全边界

- 只修改家长原生小程序首页 WXML/WXSS 和对应回归测试。
- 不修改 API、数据库、登录、权限、课程、工单、课包、通知、考勤、财务或排课逻辑。
- 本次只上传微信开发体验版 `1.0.62`，不提交审核、不正式发布。

## 验收

- 首页首屏不再出现进展长文、空课表说明和周数据。
- 有待办时只展示一个主要待办；无待办时只显示一行安全状态。
- 有下一节课才显示课程区块。
- 三个高频入口保持可点击，原有路由和权限判断不变。
- 聚焦回归、原生 JavaScript 语法、生产构建、发布门禁和线上健康检查通过。

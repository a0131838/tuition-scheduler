# TASK-20260818 国际学校英语 iTEP 结构对齐版

## 目标

将国际学校英语准备度测评从16道客观题加1道写作，升级为完整的语法、听力、阅读和写作结构；按老板决定，本轮暂不加入口语。所有内容保持博思原创，并明确不是官方 iTEP 考试。

## 已实施

- A/B/C三套平行卷，每套51项：25语法、14听力、10阅读、2写作。
- 语法10分钟、听力20分钟、阅读20分钟、写作25分钟分区计时。
- 9段原创AI合成听力音频；学生接口只返回音频地址，不返回脚本或答案。
- 服务端保存分区开始时间；分区超时会给未答题记为超时并进入下一分区。
- 小程序显示分区、倒计时、材料、听力按钮和自动保存进度。
- 报告增加语法、听力、阅读、写作四项分数；口语显示为未测。
- 写作继续使用双AI评分，一致性不足或服务不可用时转老师复核。
- 旧会话、旧报告不重算，正式业务模块不受影响。

## 产品与合规边界

- 名称：博思原创 iTEP 结构对齐版（非官方）。
- 不复制、翻译或改写iTEP原题；公开结构只用来确定模块、题量和时间。
- 不输出或冒充iTEP官方0–6分。
- 内部百分制和CEFR初步范围必须经过真实学生与外部成绩对照后才可提高可信度。
- AI合成音频在学生端和报告中披露。
- 微信仅上传开发/体验版，不自动提交审核或正式发布。

## 验收

# TASK-20260807-miniapp-school-sort-filter-audit

## Context

小程序把排序值`0`当成空值，导致本应排第一的东陵信托在“全部”中落到最后。国际学校筛选又被拆成主筛选、更多筛选和展开状态，手机上显得零碎且不易理解。目录中还混入若干私立、替代教育和专项支持项目，家长容易误以为它们与主流国际学校属于同一路线。

## Change

- 修复小程序排序对`browseRank = 0`的错误处理，确保东陵、UWCSEA、SAS、德威与NLCS依既定顺序连续置顶。
- 网页和小程序把十个国际学校筛选整合成一条横向滑动栏，移除“更多筛选/展开”。
- 复核陌生学校的官网课程、年级和全日制资料；Wise Oaks、GIG、Kindle Kids、HFSE、Lotus Bridge等保留为真实全日制学校。
- 将明确属于私立或替代教育路线的TLS Academy、The Straits Waldorf School、Lodestar Montessori School，以及专项支持项目All Hands Together移至“私立与特色学校”，并建立详细档案。
- 数据与小程序缓存版本更新为`2026-08-07-r352`。

## Non-goals

- 本次分类不是学校质量排名，也不否定私立、蒙特梭利、华德福或专项支持路线的价值。
- 不修改智能选校评分、测评、家长/员工登录、教学、排课、课包、财务、工资、工单、通知、权限或数据库。

## Verification

- 69项学校指南测试、174项后端回归、TypeScript、小程序JavaScript语法和67页小程序发布审计通过。
- 243页生产构建通过。
- 390×844浏览器验收确认筛选栏为一行横向滚动，十个按钮完整存在，东陵为第一所学校，控制台无错误。

## Risk

低。修改限于公开学校指南的排序、筛选展示和目录归类。小型学校的注册、课程与准证状态仍会变化，需要按更新计划持续复核。

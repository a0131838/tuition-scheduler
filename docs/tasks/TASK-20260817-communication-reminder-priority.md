# AI 沟通提醒统一分类与优先级

日期：2026-08-17
范围：SGT AI OS 网页端、员工小程序
正式 Tuition Scheduler：不修改

## 目标

把 Emily、教务和客服需要处理的课程提醒、教学跟进、学习报告、工单确认放到一个统一入口，并明确轻重缓急，避免员工在多个页面和无序长列表中寻找下一项工作。

## 统一规则

- P0 立即处理：已逾期、已升级，或对方已经回复等待员工继续处理。
- P1 今天处理：计划完成时间在今天。
- P2 等待回复：已经联系家长、学生或老师，当前等待对方回复。
- P3 后续跟进：尚未到处理时间，或已经设置稍后提醒。

## 业务分类

- 课程提醒：学生/家长上课提醒、老师上课提醒。
- 教学跟进：考勤、课后反馈、反馈转发。
- 学习报告：中期报告、期末报告。
- 工单确认：工单进度、老师课程安排确认。

## 本次实现

- 网页端和员工小程序共用同一套 P0-P3 判断规则。
- 页面先按优先级分段，再按业务分类筛选；每类显示待办数量。
- 每条任务显示收件人、截止时间、当前状态和优先级原因。
- 保留中英双语文案、复制、已发送、等待回复、已回复、稍后提醒、完成和升级功能。
- 状态变化后重新计算优先级，例如“已收到回复”自动进入 P0。

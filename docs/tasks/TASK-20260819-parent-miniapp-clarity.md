# TASK-20260819 — 家长端小程序信息层级与点击反馈

## 目标

在不改变任何家长数据、课表、工单、课包、通知、权限或接口规则的前提下，让家长打开小程序后先看懂“现在发生了什么、我现在要做什么、下一步会怎样”，并能明确识别可点击入口。

## 视觉与内容原则

- 视觉主张：继续使用现有克制的橙色与绿色家长品牌语言，不新增装饰性模块；用留白、单一主动作和统一箭头建立点击预期。
- 内容顺序：当前动作与结果优先，服务说明其次，历史、附件和统计按需展开。
- 交互原则：每个首屏只突出一个主要决定；可点击行都有箭头或明确按钮；长内容不删除，但默认折叠。

## 已实施

1. 家长首页
   - 常用服务由类似普通文字的宫格改为整行可点击入口，并补充统一箭头。
   - “联系服务团队”前置，课程、服务请求与资料入口保持原路径。
   - 本周统计移入“本周数据”折叠区，降低首屏噪音。

2. 服务进展
   - 首屏新增“现在需要您做”，直接显示最重要的家长动作与截止信息。
   - 服务记录、周摘要和时间线默认收起，保留完整资料但不抢占首屏。

3. 服务请求列表与详情
   - 每张请求卡直接说明“下一步”，并通过箭头强化可点击性。
   - 详情页先显示当前动作和最终结果，再显示请求正文。
   - 长正文、附件和历史资料按需展开；返回动作回到请求列表，不跳回首页。

## 安全边界

- 只修改 `miniapp/boss-academic-parent` 的展示与本地交互状态。
- 不修改 API、数据库、权限、登录、课表、工单执行、课时扣减、考勤、工资、财务或真实消息发送。
- 不删除历史内容；所有被弱化的资料仍可由家长主动展开。
- 微信只上传开发版本，不自动提交审核或正式发布。

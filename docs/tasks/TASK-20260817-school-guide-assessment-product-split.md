# TASK-20260817 新加坡学校指南测评产品拆分（本地测试版）

## 状态与发布边界

- 状态：PATHWAY_V4 测试发布候选；服务器仅增加向后兼容的新测评产品支持，微信仅上传开发测试版。
- 不提交微信审核、不发布正式版，当前正式小程序用户仍使用原版本。
- 原有已完成测评报告不重算；新规则只用于部署后新建的测评会话。
- 题库仍是 V1.4-20260805 / pilot，不因本次代码调整自动升级为正式量表。

## 问题根因

1. 原界面虽选择“国际学校/政府学校AEIS”，但除DSA外，组卷主体仍为同一套英语、数学、认知推理和科学混合卷。
2. 原报告把各能力域百分数做简单平均，产生一个没有明确用途的大总分。
3. 科学被放入AEIS报告，且国际学校报告没有明确英语量尺边界。
4. 不同产品的复测会共用A/B/C排除记录，容易误阻止学生改测另一条路径。

## 已完成的产品拆分

### 1. 国际学校英语入学准备度

- 只选英语题，不混入数学、科学或认知推理。
- 结果显示 /100 内部得分和“CEFR初步参考范围（待校准）”。
- 固定声明：不是iTEP或CEFR官方成绩，不能单独预测学校录取。

### 2. AEIS小学入学准备度

- 报告分为“CEQ英语资格准备”与“AEIS小学数学准备”。
- 英语和数学分开显示，不合并总分，不包含科学。
- 仅适用6–8岁与9–11岁年龄段。

### 3. AEIS中学入学准备度

- 英语与数学独立评分，不合并总分，不包含科学。
- 仅适用12–14岁与15–17岁年龄段。

### 4. 低龄边界

- 3–5岁不进入在线CEFR或AEIS卷。
- 页面直接提示由老师安排一对一观察评估。

## 兼容与安全

- 旧 INTERNATIONAL /新 INTERNATIONAL_ENGLISH 和旧 MOE_AEIS /新AEIS小学或中学保持评估码过渡兼容。
- 历史会话继续使用 LEGACY_V1 计分；新产品使用 PATHWAY_V4。
- 不同测评产品各自管理A/B/C复测记录，不再互相占用。
- 学生提交后即使写作仍在等待老师复核，也可以直接开始下一套平行卷；每次记录独立保留，不覆盖上一轮。
- 同一学生、同一路径在24小时内最多开始3套卷，优先轮换A/B/C，避免短时间记忆题目影响结果。
- 无数据库迁移，不修改学生、课程、排课、课包、财务、工单、登录或权限数据。

## 验证记录

- 测评专项测试：16/16通过。
- 题目领域校验：国际学校只有英语；AEIS只有英语与数学。
- A/B/C卷无卷内重复，三卷顺序/选题不完全相同。
- 每条产品路径只保留1道写作；国际学校为16道语言/阅读客观题+1道写作，AEIS小学为CEQ英语准备12题+1道写作+数学12题，AEIS中学为英语14题+1道写作+数学14题。
- 阅读题改为逐篇绑定事实、推断、词义和写作目的，不再复用凭常识可猜的通用选项；数学按年龄覆盖应用、分数比例、几何、代数与数据。
- 写作提交给新加坡区域的两次独立AI评分；两次分差超过门槛、模型不可用或结果不合规时自动转老师复核，不伪造分数。
- 报告新增语言运用、阅读理解、写作、数学分项与证据数量；明确本轮不测听力口语。CEFR只显示按年龄分层的初步参考范围（待样本校准）。
- 等待老师复核和已完成页面均可立即开始下一套平行卷；历史记录显示卷别与状态，复测不会重复消耗原评估码。
- 小程序发布审计：69页通过，0项错误。
- 后端回归测试180/180、TypeScript、251页生产构建与测评专项测试通过。

## 上线前必须完成

1. 学术主管按三个产品分别复核A/B/C卷，尤其是英语阅读、写作和口语覆盖。
2. 用真实学生做受控UAT，记录题目区分度、实际用时、人工评分一致性和异常题。
3. CEFR参考切分点必须经外部标准成绩对照样本校准；未校准前只能保留“初步参考范围”标签。
4. 体验版真机流程验收通过后，再单独决定是否提交微信审核和正式发布。

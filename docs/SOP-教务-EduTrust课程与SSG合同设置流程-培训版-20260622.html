EduTrust Course Setup and SSG PEI Contract Workflow

这份 SOP 解释现在系统新增的 EduTrust 功能怎么用。重点不是马上给家长签，而是先把课程、Course File、合同 Schedule、学生证据四层资料准备好，未来新学生达到条件后，系统才能生成 SSG Standard PEI-Student Contract v4.0 并发送签字链接。

适用对象教务 / 管理层 / 合规负责人
主入口Admin -> EduTrust Readiness
版本日期2026-06-22
先记住： 现在不能把所有学生直接切成 SSG 合同。必须先完成课程映射、Course File、Contract Schedule Setup，并把课程状态设为 PERMITTED、Course File 设为 APPROVED，课包小时数达到最低要求，才可以给新学生走 SSG v4 合同。

这套功能到底解决什么问题？

系统现在做了什么

  1. 不改现有运营课程名，避免教务找不到课程。
  2. 给每个课程增加 EduTrust 合规映射层。
  3. 把官方合同 Schedule A-D 的学校资料集中配置。
  4. 未来新学生签 SSG v4 合同时自动带出课程和政策资料。
  5. 如果资料不完整，系统阻止发送 SSG 签字链接。

系统没有替你决定什么

  1. 不会自动判断学校是否已获得 SSG permission。
  2. 不会替管理层决定退款比例。
  3. 不会替学校确认 FPS 是否适用。
  4. 不会把旧学生/旧合同自动改成 SSG 合同。
  5. 不会绕过官方合同的固定条款。
一句话： 系统负责“记录、自动填、拦错误”；官方政策和学校承诺仍必须由管理层确认。

整体流程：从课程准备到新学生签约

1. 课程映射
2. Course File
3. Contract Schedule
4. 管理层确认
5. 学生证据
6. 建新课包
7. SSG 合同签署

课程层要先完成

  1. 课程纳入 EduTrust。
  2. 合规课程名确认。
  3. 最低总小时数至少按学校策略设定，当前建议 50 小时起。
  4. 授课方式设为 One-to-one / 一对一。
  5. Course File 内容完整并批准。

学生层以后再发生

  1. 新学生购买符合条件的 EduTrust 课包。
  2. 系统创建 SSG v4 PEI contract draft。
  3. 系统检查 Schedule A-D 是否完整。
  4. 教务预览确认后发送签署链接。
  5. 签署后保存合同 PDF、发票、付款/FPS 证据。
现在的重点是前四步：把课程资料先整理好。否则未来新学生到了，也不能安全签 SSG 官方合同。

Step 1：进入 EduTrust Readiness 页面

路径

  1. 登录后台 Admin。
  2. 左侧菜单点击 EduTrust Readiness / EduTrust 合规整改。
  3. 先看顶部统计：当前课程、建议纳入课程、已保存映射、低课时风险。
  4. 再看 Suggested Course Lines，确认哪些课程线会用于 EduTrust 主证据。
如果某门课只是普通补习课，不准备作为 EduTrust 主证据，就保持 Not for EduTrust。

Step 2：课程映射，不要改教务熟悉的运营课程名

怎么填

  1. EduTrust 主证据：选择 Yes / 纳入，表示这门课将作为申请证据课程。
  2. EduTrust 课程线：选择 AEIS、国际学校入学、学术英文、学科桥梁等官方风格课程线。
  3. 最低总课时：建议至少 50 小时，一对一也可以，但课包必须达到这个小时数。
  4. 授课方式：一对一课程选择 One-to-one。
  5. 合规课程名：写给 SSG/合同/证据看的正式课程名。
  6. 对外展示名：可以保留家长看得懂的名字。
  7. 点击 Save mapping / 保存映射。
课程映射区：运营课程名不变，只增加合规映射资料。
SGT Manage EduTrust SOPStep 2

Step 3：填写 Course File / 课程文件

Course File 是什么

Course File 是 EduTrust 审核会看的课程证据，不是排课表。它证明学校知道这门课教什么、怎么教、怎么评估、谁批准。

必须沉淀的内容

  1. Course write-up / 课程说明
  2. Admission requirements / 入学要求
  3. Learning outcomes / 学习成果
  4. Syllabus / 课程大纲
  5. Lesson plan / 课时计划
  6. Assessment plan / 评估计划
  7. Teacher deployment / 老师配置
  8. Academic Board / Examination Board approval
  9. Course review / 课程复盘
Course File 折叠区：先写草稿，管理层/学术负责人确认后把状态设为 APPROVED。
SGT Manage EduTrust SOPStep 3

Step 4：填写 Contract Schedule Setup / 官方合同 Schedule 设置

这个区域最容易误解

这里不是自己写合同条款。官方 SSG v4 固定条款已经锁定；这里填的是官方合同 Schedule A-D 里要求学校提供的信息。

必须由学校确认

  1. 课程获准时长、开课/结课规则。
  2. 入学要求、课程安排、假期、评估、结果发布时间。
  3. 是否有 industrial attachment，通常补习/预备课程填 No / N.A.。
  4. 杂费，如没有就填 N.A.。
  5. Schedule D 退款比例和 working days。
  6. Late payment 宽限期。
  7. FPS 是否需要、provider、policy number。
Contract Schedule Setup：这些值会自动填入 SSG Standard PEI-Student Contract v4.0 的 Schedule A-D。
SGT Manage EduTrust SOPStep 4

哪些字段是“必要的”？谁来确认？

资料是否必要谁确认怎么填
课程合规名、课程线、最低小时数必要管理层 + 合规负责人用于申请、合同标题和课包小时校验。
Course File必要学术负责人 / Academic Board内容完整后状态设为 APPROVED。
Schedule A 课程详情必要学术负责人 + 管理层入学要求、课程安排、评估、结业证明不能乱填。
Schedule B 费用必要教务 + 财务系统会从课包金额带入，但付款日期/分期安排要确认。
Schedule C 杂费必要财务 + 管理层没有杂费也要填 N.A.，不要留空。
Schedule D 退款政策必要且高风险管理层百分比和 working days 是学校承诺，不能由普通教务随意决定。
Late payment 宽限期必要财务 + 管理层例如 7 days；具体按学校政策。
FPS 信息按课程/学生情况财务 + 管理层如果勾选 FPS required，provider 和 policy number 必须填。
停止点： 退款政策、FPS、official permission 没确认时，不要把课程标成可以对外签 SSG 合同。
SGT Manage EduTrust SOP必要字段

Step 5：学生证据与 C7 Outcomes

什么时候用

当真实学生开始上 EduTrust 课程后，需要把每个学生的学习过程证据沉淀下来，用于 EduTrust Section A/B 和 C7 Outcomes。

每个学生建议记录

  1. Diagnostic assessment / 入学诊断
  2. Individual learning plan / 个性化学习计划
  3. Progress review / 进度复盘
  4. Final assessment / 结课评估
  5. Completion record / 完成记录
  6. Attendance evidence note / 出勤证据
  7. Contract/FPS evidence note / 合同与付款证据
  8. Outcome summary / 成果总结
学生证据页：不是签合同前必须马上填完，但三年达标计划必须从第一批学生开始记录。
SGT Manage EduTrust SOPStep 5

未来新学生怎么签 SSG 官方合同？

新学生签约流程

  1. 先在 `/admin/edutrust` 完成课程映射、Course File、Contract Schedule Setup。
  2. 确认课程状态为 PERMITTED，Course File 为 APPROVED。
  3. 给新学生建立符合最低小时数的 EduTrust 课包，例如至少 50 小时。
  4. 打开该课包的 Package Contract Workspace / 课包合同工作台。
  5. 如果课程条件全部满足，会出现 SSG v4 PEI contract 创建入口。
  6. 创建 SSG 合同草稿后，系统检查 Schedule A-D 是否完整。
  7. 检查通过后，教务发送签字链接给家长。
  8. 家长签署后，系统保存合同 PDF，再继续 invoice/payment/FPS evidence。
课包合同工作台：普通合同入口仍保留；SSG 入口只在课程、文件、小时数、Schedule 设置都达标时出现。

为什么有时候看不到 SSG 合同按钮？

常见原因

  1. 该课程没有勾选 EduTrust 主证据。
  2. Permission status 不是 PERMITTED。
  3. Course File status 不是 APPROVED。
  4. 课包小时数低于最低小时数。
  5. Contract Schedule Setup 没填完整。
  6. FPS 勾选了 required，但 provider/policy number 没填。

正确处理

  1. 回到 `/admin/edutrust` 检查课程映射。
  2. 补 Course File，并由负责人确认。
  3. 补 Schedule A-D 的必填资料。
  4. 由管理层确认退款和 late payment。
  5. 重新保存 mapping。
  6. 回课包合同工作台再试。
系统阻止发送签字链接不是 bug，而是保护：避免把有空白 Schedule 或未确认政策的官方合同发给家长。

教务每天怎么用？管理层每周看什么？

教务日常动作

  1. 不要改老课程名，按映射层维护合规名。
  2. 新课程先填 Course File 草稿。
  3. 新学生课包创建前确认小时数达标。
  4. 合同发出前确认没有系统报错。
  5. 学生开始学习后补学生证据。

管理层/合规负责人动作

  1. 确认哪些课程纳入 EduTrust 主证据。
  2. 审批 Course File。
  3. 确认 Schedule D 退款政策。
  4. 确认 late payment 和杂费。
  5. 确认 FPS 适用规则。
  6. 每月检查 C7 outcome 是否有记录。
权限建议： 教务可以录入草稿；涉及 PERMITTED、APPROVED、退款、FPS 的最终状态，必须由负责人确认后再保存。

常见错误

不要这样做

  1. 为了快，直接把普通补习合同当 SSG 合同发给家长。
  2. 把运营课程名改成很长的官方名，导致教务找不到课程。
  3. 退款比例随手填一个大概值。
  4. Course File 还没批准就把课程设为可签。
  5. 50 小时以下课包也尝试走 EduTrust 合同。
  6. FPS 不确定时留空但继续签。

应该这样做

  1. 运营名不变，合规名放在 EduTrust 映射层。
  2. 先做课程资料，再做学生合同。
  3. 所有政策字段写 N.A. 或确认值，不留空。
  4. 先由负责人确认，再设 APPROVED / PERMITTED。
  5. 让系统拦截不完整合同。
  6. 签完后保存合同、invoice、payment/FPS evidence。

第一批整改建议：按这个顺序做

阶段负责人要做什么完成标准
第 1 步管理层决定哪些现有课程纳入 EduTrust 主证据。课程线清单确认。
第 2 步教务在 `/admin/edutrust` 保存课程映射。每门目标课程有合规名、50 小时、一对一。
第 3 步学术负责人填写 Course File。核心字段完整，状态可设 APPROVED。
第 4 步管理层 + 财务确认退款、杂费、late payment、FPS。Schedule Setup 不留关键空白。
第 5 步教务试建一个符合条件的新课包并检查合同工作台。能看到 SSG 创建入口，或明确知道缺什么。
第 6 步合规负责人抽查生成合同预览。官方条款不改，Schedule 值正确。
建议不要一次性把 17 门课全部改完。先选 2-3 门最适合申请证据的课程做完整样板，再复制方法到其他课程。

最终检查清单 / Final Checklist

课程可以准备签 SSG 合同前

  1. EduTrust 主证据 = Yes。
  2. Course line 正确。
  3. Compliance name 正确。
  4. Minimum total hours >= 50。
  5. Delivery mode = One-to-one。
  6. Permission status = PERMITTED。
  7. Course File status = APPROVED。
  8. Contract Schedule Setup 必填项完整。

新学生发签字链接前

  1. 学生资料完整。
  2. 课包属于已准备好的 EduTrust 课程。
  3. 课包小时数达标。
  4. 费用和付款日期正确。
  5. Schedule D 退款政策正确。
  6. FPS 信息按政策填写。
  7. 预览合同无空白关键字段。
  8. 再发送签字链接。
完成结果： 未来新学生签约时，系统会用官方 SSG Standard PEI-Student Contract v4.0，自动填入学校确认的 Schedule A-D 内容，并保存电子合同证据。

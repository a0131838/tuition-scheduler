# 续费确认、审批待办与限额续课操作指南

适用版本：2026-11-06-r506。员工先刷新网页，使用自己的岗位账号。

## 一、现在这笔已付款、待家长补签的申请

1. 财务已提交的申请无需重开票、重开收据或重复提交。
2. Jasmine 使用 **Admin 管理账号**进入 **Todo Center / 待办中心**，在页面最上方打开 **Renewal actions / 续费待办**。也可从 **Approval Inbox / 审批提醒中心**进入。
3. 核对学生、本次发票、课时、金额、收据和申请原因，批准或退回。
4. 管理批准后，Sharilyn 使用本人授权 **Finance 财务账号**，从财务工作台或审批提醒中心打开 **Activate renewal / 激活续费**，核对后激活。
5. 激活后家长合同仍显示待补签，财务待办转为补签跟进；家长完成签字后待办消失。付款与签字是独立事实。

## 二、新版普通课时协议下的同条件续费

入口：续费跟进 → **Renewal orders / 续费确认单**。Admin 和 Finance 导航也有“续费确认单”；销售可直接打开 `/admin/renewals/orders`。

这是“原已签协议＋每次家长明确确认”，不是自动续费或自动扣款。

1. **教务**：先按原流程准备本次续费合同的课程、课时和金额，生成正式待签草稿；到续费确认单选择该合同。系统核对原已签新版协议，条件一致才显示建单表。填写学习计划、服务起止日期和付款期限。续费前学习进展报告仍在原独立入口准备，不会因此重置。
2. **Sales／Jasmine**：打开本单，填写与家长沟通确认的课包、课时、价格和日期，点击“销售确认”。
3. **Jasmine 管理账号**：在待办中打开本单，核对是否属于普通直收补习业务，并填写本次适用性与政策复核依据，点击“批准本次续费依据”。涉及法定PEI合同的课程不使用此简化入口。
4. **家长**：员工审核后复制“家长确认单”链接发送；系统不会自动发送。家长阅读金额、课时、服务期、付款期限和原协议正文，输入原签约家长完整姓名、勾选同意并确认。无需重复绘制整份合同签名。未确认的链接14天有效，销售或管理者可刷新，旧链接随即失效。
5. **Finance**：根据锁定的续费信息在原 **Package Billing / 课包账单**开本期发票，再回本单关联。只能关联金额、归属及周期相符且未重复占用的本期发票；锁定后不可随意替换。
6. **Finance**：收款后按原流程登记付款和开收据、完成收据审批；回本单点击“核验全款并激活”。系统重新核对足额已审批收款，保存收据参考及激活人和日期，只入账一次。
7. 成功后显示“依据原协议续费已确认”，不会将本次合同伪装成家长重新签字。对应的本期续费跟进任务会结束，历史报告保留。

**第一次采用新条款之前**：旧版协议不能自动升级，家长需按完整签约流程签署包含新版续费条款的协议。新版条款仅作为后续同条件续费的基础，每次仍须明确确认。条件变化也走完整签约。不得改写历史已签协议或复制旧签名。

## 三、确实需要未付款先续课时

默认先足额核款再激活；以下是可选的、逐次审批的例外。

1. 先完成上述销售确认、管理审核、家长确认和本期发票关联。
2. Jasmine 管理账号展开“批准未付款限额续课”，填写最多分钟数、最大授信金额、到期日期、催款负责人和原因。
3. 临时额度不得超过本期课时和金额；分钟数按本期单价折算后不能超过批准金额。到期日不得超过30天及本期服务结束日，也不能早于服务开始日。这里的30天是系统的内部上限，不代表自动授信30天。
4. 授权 Finance 使用独立账号点击“放行已批准临时课包”。系统建立带明确“未付款临时续课”标记的专用课包。排课、扣课受其有效期与剩余分钟限制；没有创建付款或收据。
5. Finance 在待办里持续跟进收款，超过批准日期会标红。已放行额度的单据不能直接取消，须先对账。
6. 足额收款且收据已审批后，Finance 回本单核验并激活。临时课包转为本次正式已付款课时的一部分，保留余额并延长至已确认服务期；原课包只补入尚未分配的部分。

**例子**：续费50小时，先批准临时2小时，已使用1小时。全款核准后，临时课包保留1小时，原课包新增48小时；合计可用49小时，加上已上的1小时正好50小时。不要再手工给原课包加50小时。

## 四、核对与异常处理

- 待办随阶段变化：管理待审核 → 财务核款／激活 → 补签或确认跟进；处理完成后移出相应队列。
- 保存后页面显示结果；提交中按钮锁定。网络结果不明时先重新打开记录核对，不要连续重做。
- 激活后已核准的收据被修改、退回或与发票不符，会出现财务对账提醒；系统不自动改写已发生的上课及收款事实。
- 原协议／本单已变化、不支持同条件续费时，由管理取消未放临时额度的确认单，再返回完整签约。已激活或已放额度须先人工对账。
- 同条件简化流程暂限：普通直收、一对一、按分钟的课时包、整数新币课包金额。旧协议、变化的条款、PEI／EduTrust课程、全托管、共享、团课、月包和合作方结算使用原流程。
- 这次上线不会自动给任何真实学生建单、批准、续课或加课时；具体业务操作由对应员工完成。

Academic Operations SOP / 教务培训流程

上海新卓思学生建档与课时包创建流程
New Student Setup + HOURS Package

这份 SOP 专门给教务：当新增上海新卓思学生时，学生档案怎么选来源；创建课时包时，如何选择学生、课程、课时包分钟数、 结算模式，确保后续能进入合作方结算。

适用角色教务 / Admin
核心字段学生来源 + 结算模式
版本日期2026-07-08

一句话答案

新增新卓思学生： 学生来源选 上海新卓思 （Sister Company)。 创建课时包： 类型选 HOURS / 课时包，结算模式选 Online: Package End。
注意： 这份 SOP 的截图使用示例填写状态，没有点击最终保存或创建按钮。

先记住

  1. 系统靠 学生来源 分辨上海新卓思学生，不靠备注、不靠学生名字。
  2. 上海新卓思来源必须选：上海新卓思 （Sister Company)。
  3. 课时包类型用 HOURS / 课时包，不要选月卡或旧版次数包，除非管理明确说明。
  4. 合作方线上结算必须选 Online: Package End，否则不会进入线上课包完结结算。
  5. 最后一步一定看右侧 Package summary / 课包摘要，确认学生、课程、分钟数、结算模式无误再创建。

完整流程

  1. 进入 Students / 学生，点击 Add / 新增。
  2. 填写学生姓名、学校、年级，学生来源选择 上海新卓思 （Sister Company)。
  3. 保存后用 All Students / 全部学生 + 来源筛选复查。
  4. 进入 Packages / 课包，点击 Create Package / 创建课包。
  5. 第 1 步选择学生、课程、类型 HOURS。
  6. 第 2 步填写总分钟数、付款状态。
  7. 第 3 步选择 Online: Package End，第 4 步确认摘要后再创建。

步骤 1：新增上海新卓思学生

Students → Add

新增学生时，最关键的是学生来源。来源选错，后续合作方结算就识别不到。

操作：
  • 进入 Students / 学生。
  • 点击 Add / 新增。
  • 学生来源选择 上海新卓思 （Sister Company)。
图 1： 类型可以按实际业务选择，但学生来源必须是上海新卓思 Sister Company。

步骤 2：保存后复查学生来源

All Students + Source Filter

新建完成后，不要只看今日新增。用全部学生视图和来源筛选确认学生确实归到上海新卓思。

操作：
  • 打开 All Students / 全部学生。
  • 来源筛选为 上海新卓思 （Sister Company)。
  • 确认筛选结果包含刚新增的学生。
图 2： 如果筛选不到，先回学生详情编辑来源，不要继续创建课包。

步骤 3：创建课包第 1 步

Student + Course + HOURS

选择学生和课程。上海新卓思常规课时包类型用 HOURS / 课时包。

操作：
  • 进入 Packages / 课包。
  • 点击 Create Package / 创建课包。
  • 搜索并选择新卓思学生，确认课程，类型选择 HOURS / 课时包。
图 3： 右侧摘要会同步显示学生、课程和课包类型，发现学生选错要马上改。

步骤 4：创建课包第 2 步

Minutes + Payment

填写总分钟数。合作方默认按课时逻辑管理，系统会提示合作方默认课时规则。

操作：
  • 填写 totalMinutes / 总分钟数。
  • 根据实际情况填写付款状态。
  • 截图里的发票金额只是演示填表通过，不代表实际应收；最终以业务确认金额为准。
图 4： 在还没选合作方结算模式前，页面可能暂时显示直客发票闸门；第 3 步选好合作方模式后会变成合作方流程豁免。

步骤 5：创建课包第 3 步

Settlement Mode

这是最容易漏掉的一步。没有选结算模式，学生来源正确也不会进合作方结算。

操作：
  • 状态保持 ACTIVE。
  • Settlement Mode / 结算模式 选择 Online: Package End。
  • 右侧摘要应显示 Partner flow exempt / 合作方流程豁免。
图 5： 这是合作方线上课包完结结算的关键字段。

步骤 6：最终确认后创建

Review + Create

最后一步不要急着点创建。先看右侧摘要，确认所有关键字段正确。

创建前必须核对：
  • Student / 学生是否正确。
  • Course / 课程是否正确。
  • Package type 是否为 HOURS。
  • Minutes 是否正确。
  • Settlement Mode 是否为 Online: Package End。
  • Invoice gate 是否显示 Partner flow exempt。
图 6： 只有右侧摘要全部正确，才点击 Create / 创建 / 创建课包。

常见错误

错误 1：学生来源没选新卓思

后续合作方结算不会识别。先回学生详情把来源改正确。

错误 2：只创建课包，没选结算模式

课包不会进入线上待结算。需要把课包模式改成 Online: Package End。

错误 3：选了月卡或旧版次数包

除非管理明确说明，否则新卓思常规按 HOURS / 课时包建。

错误 4：右侧摘要没看就创建

学生、课程、分钟数、结算模式任一项错，后续结算都会错。

不要做： 不要为了绕过发票闸门乱勾豁免；新卓思课包应通过正确的 Settlement Mode 进入合作方流程。

最终检查表

  • 学生来源 = 上海新卓思 （Sister Company)
  • 学生保存后可以在 All Students + 来源筛选中找到
  • 课包类型 = HOURS / 课时包
  • 总分钟数与实际销售课时一致
  • Settlement Mode = Online: Package End
  • 右侧摘要显示 Partner flow exempt / 合作方流程豁免
  • 最后一步核对无误后才点击 Create
